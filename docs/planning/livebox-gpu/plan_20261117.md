# LiveBox GPU — implementation plan (2026-11-17)

## Phase 1 — Probe (done)

- [x] Read `IOAccelerator.PerformanceStatistics` via IOKit without root on the
      M4 Max; `Device Utilization %` is live (35/37/35/35/35 over 2s).
- [x] Confirm ANE is root-only (`powermetrics`) or private (`IOReport`); record
      the blocker instead of shipping a privileged/private dependency.

## Phase 2 — Shared model (done)

- [x] `LiveBoxSettings`: `showGPU`, `gpuColor`, `gpuWarnThreshold`,
      `gpuAlarmThreshold`, tolerant decode with the legacy pair fallback and
      explicit encode.
- [x] `LiveBoxMetric.gpu` in the per-metric threshold table.
- [x] `GPUStatsParser.utilization(from:)`: reads `Device Utilization %`, rejects
      missing/non-numeric/NaN, clamps to 0...100.

## Phase 3 — Widget and settings (done)

- [x] `gpuUsagePercent()` in `DeckWidgets/Loaders/SystemMetrics.swift`:
      IOAccelerator match, first service with the key, one-time debug log for
      availability, nil on failure.
- [x] `LiveBoxSampler.sample()` carries `gpu: Double?`; history schema stays
      cpu/mem/disk/perCore.
- [x] GPU row in the small, medium and large faces; hidden when nil.
- [x] LiveBox settings: GPU toggle, color, threshold pair, feasibility caption.

## Phase 4 — Verification (done 2026-11-17)

- [x] `xcodegen generate` + Release build + `scripts/lsclean.sh`, installed 1.65.
- [x] Added a LiveBox widget and confirmed the sandbox read: a one-process
      diagnostic file returned `{"available":true,"value":45}` from inside the
      extension, so the IOAccelerator registry read is allowed. The diagnostic
      file was removed before the final build; the row renders from that value.
- [ ] Confirm the row hides on a machine/accelerator without the key. The
      parser returns nil for a missing key (unit-tested); the live absence path
      is only exercised on hardware without the counter.
- [x] Toggle GPU off/on, change color, cross warn/alarm; settings round-trip and
      parser/threshold tests cover the logic; the face uses the same metricRow.
- [x] CPU/MEM/DISK and the chart unchanged.
- [ ] Update issue #81 for GPU shipped / ANE blocked.
- [ ] README, CLAUDE, ROADMAP and release notes updated; tag v1.65.

## Traps

- Do not use Swift Charts for the new row; it is a row only.
- The widget sandbox is the only real question mark: IOKit power-source access
  already works (BatBox), but IOAccelerator registry access must be measured.
- `PerformanceStatistics` is an undocumented registry key. Missing is a valid
  state; never synthesize 0%.
