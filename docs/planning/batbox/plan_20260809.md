# BatBox — Implementation Plan

**Slug:** `batbox` · **Plan date:** 2026-08-09 · **Source:** `docs/planning/batbox/prd.md` (approved)

Template: NetBox shell (`Sources/NetBox/*` + `Sources/NetBoxCore/*` +
`Tests/NetBoxCoreTests/*`). Phase 0 spike is DONE (see prd.md §3): IOKit
dictionary keys verified on this machine; cycle count needs the `ioreg` fallback.

## Phase 1 — BatBoxCore pure logic (TDD)

**Goal:** A tested pure library for battery math, state classification, and
formatting; no timers, no IOKit.

**Files touched:** `Sources/BatBoxCore/Models.swift`, `Sources/BatBoxCore/BatteryMath.swift`,
`Sources/BatBoxCore/Formatters.swift`, `Sources/BatBoxCore/IOregParser.swift`,
`Tests/BatBoxCoreTests/BatteryMathTests.swift`, `Tests/BatBoxCoreTests/FormatterTests.swift`,
`Tests/BatBoxCoreTests/IOregParserTests.swift`, `Package.swift`

**Steps (RED → GREEN per step):**
1. Register `BatBoxCore` library target + `BatBoxCoreTests` test target in
   `Package.swift` (mirror NetBoxCore entries).
2. Models: `BatterySnapshot` (levelPercent: Double?, timeToEmptyMinutes: Int?,
   timeToFullMinutes: Int?, isCharging: Bool, isCharged: Bool, isPresent: Bool,
   cycleCount: Int?, powerSource: PowerSource where `case battery, ac`) and
   `LevelTier` (`high, medium, low`).
3. `BatteryMath.percent(current:max:)` — clamps 0...100; max ≤ 0 → nil.
   `BatteryMath.tier(percent:)` — >50 high, 20...50 medium, <20 low.
   `BatteryMath.timeMinutes(seconds:)` — seconds → minutes Int, 0 → nil.
4. `BatteryFormatters`: `formatPercent` (`71%`), `formatTime(minutes:)`
   (`6h 34m`, `45m`, `—` for nil), `formatCycles` (`107`, `—` for nil),
   `formatState(isCharging:isCharged:powerSource:)`
   (`Charging`/`Discharging`/`Full`/`AC Power`).
5. `IOregParser.cycleCount(from:)` — parses `"CycleCount" = 107` from ioreg
   stdout; nil on garbage/missing.
6. Tests: percent math (clamp, zero max), tier boundaries (50/20 exactly),
   time formatting (seconds rounding, zero → nil), state classification matrix,
   ioreg parser (valid, missing, garbage).

**Verification:** `swift test` — all BatBoxCoreTests green.
**Dependencies:** none (pure logic).

## Phase 2 — Shell scaffold + battery loader + store

**Goal:** The widget builds and runs, reading real battery data, with the shell
untouched in behavior.

**Files touched:** `Sources/BatBox/{AppMain,Settings,MetricsStore,ContentView,
SettingsView,NativeWidgetDetector}.swift` (copied from NetBox, renamed),
`Sources/BatBox/BatteryMetrics.swift` (new loader), `Package.swift`

**Steps:**
1. Copy NetBox shell files → `Sources/BatBox/`, rename types
   (`NetBoxSettings` → `BatBoxSettings`, bundle ids `com.netbox.*` →
   `com.batbox.*`, `NETBOX_DEBUG` → `BATBOX_DEBUG`), register the
   executableTarget in `Package.swift`. Build green with the shell intact.
2. Trim `BatBoxSettings` to the PRD back face: `showChart = true`,
   `showStatus = true`, `levelColor = CodableColor(.green)`,
   `launchAtLogin = false`.
3. `BatteryMetricsLoader.snapshot()` — IOKit `IOPSCopyPowerSourcesInfo` →
   read `Current Capacity`, `Max Capacity`, `Is Charging`, `Power Source State`,
   `Time to Empty`, `Time to Full Charge`, `Is Present`; cycle count via
   `Process` running `ioreg -rn AppleSmartBattery` + `IOregParser`. Returns a
   pure `BatterySnapshot`. Missing keys → nil fields; never throws.
4. `MetricsStore`: replace network sampling with `snapshot()` on the 1s timer;
   publish `header` values (level, time, state), `history: [Double]` (level %,
   capacity 90), `cycleCount`, `isPresent`. Empty/no-battery → all nil, store
   keeps ticking.

**Verification:** `swift build` green; `swift run BatBox` shows header matching
`pmset -g batt` (level ±1%, time within a minute); window bounds ≈ content
height; sits behind windows; `swift test` still green.
**Dependencies:** Phase 1.

## Phase 3 — Front face

**Goal:** The card shows header, chart, and status list per the PRD, with
dynamic height.

**Files touched:** `Sources/BatBox/ContentView.swift`, `Sources/BatBox/AppMain.swift`

**Steps:**
1. Header: `LEVEL` + `TIME` labels using the shell `RateLabel` pattern —
   LEVEL dot color from `BatteryMath.tier`, TIME shows `6h 34m` / `to full`
   when charging. Gear pinned right.
2. Chart: single level-% series, fixed Y domain `0...100`, 90 samples,
   level color, `chartXAxis(.hidden)` + trailing axis marks at 0/50/100.
   Hide header labels + chart when `showChart` off (shell pattern).
3. Divider + status list: fixed 3 rows (State / Time / Cycles), label left,
   value right in level color, `—` for nil. Hide when `showStatus` off.
4. No-battery empty state: `isPresent == false` → header `—`, chart/list
   hidden, card keeps the settings gear.
5. Dynamic height: keep `PanelHeightKey`/`reportHeight()` untouched; update
   the hardcoded 358 constants in the `--debug-render`/`--debug-front` helpers
   to BatBox's own front height (prd.md §7).

**Verification:** `swift build -c release`; `swift run BatBox --debug-flip`
renders the settings face; `--debug-render`/`--debug-front` PNGs look right;
CGWindowList bounds = content height; corners rounded; widget behind windows.
**Dependencies:** Phase 2.
