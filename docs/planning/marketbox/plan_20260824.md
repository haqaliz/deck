## Conventions for this repo (the deck-plan blueprint is older than the shell)

- Widgets live in `native/DeckWidgets/<Name>Widget.swift` (WidgetKit), not an SPM
  `Sources/` tree; the repo is xcodegen + `Deck.xcodeproj`, not `swift build`.
- New source files require `xcodegen generate --spec native/project.yml` before
  build/test (xcodegen enumerates files at generation time; a new test file is
  otherwise silently not compiled).
- Pure logic is tested with XCTest in `DeckSharedTests` (CI:
  `xcodebuild test -project native/Deck.xcodeproj -scheme DeckSharedTests
  -derivedDataPath native/build.noindex CODE_SIGNING_ALLOWED=NO`).
- Loaders stay thin; the repo tests parsers/aggregation over fixtures, never the
  network. All tricky logic here lives in a pure `MarketBuilder` core.
- UI is verified by a Release build into `native/build.noindex`, install to
  `/Applications`, `scripts/lsclean.sh`, then re-add from the gallery at all
  three sizes (never skip lsclean — see CLAUDE.md).

**Tests:**

## Phase 3 — Resolver + converter + builder + formatter (pure core, TDD)

**Goal:** symbols resolve to kinds; prices convert to the display currency; rows/
notes/fatal-outcome are decided by one pure function; prices format readably.

**Files touched:**
- `native/Shared/MarketBoxCore.swift` (new) — `MarketSymbolResolver`,
  `MarketConverter`, `MarketBuilder`, `MarketPriceFormatter`.
- `native/SharedTests/MarketBoxCoreTests.swift` (new).

**Steps:**
1. `MarketSymbolResolver.resolve("BTC") -> MarketKind` — curated crypto map
   (`BTC→bitcoin, ETH→ethereum, TON→the-open-network, USDT→tether, SOL→solana,
   XRP→ripple, DOGE→dogecoin, ADA→cardano, BNB→binancecoin, LTC→litecoin,
   DOT→polkadot, AVAX→avalanche-2, LINK→chainlink, TRX→tron`), `GOLD` → gold,
   curated fiat ISO allowlist → fiat, else unresolved. Exposes
   `cryptoID(for:) -> String?` and `isFiatISO(_:)`.
2. `MarketConverter` (pure) — inputs: `display: MarketCurrency`, `tmn: Double?`
   (Toman per USDT), `usdPerG: Double?` (gold per gram, ÷ 31.1035 done by the
   caller or here), `rates: [String: Double]` (per-USD from open.er-api).
   - `price(usd: Double) -> Double` → `usd` for `.usd`, `usd * tmn` for `.irt`,
     `usd * tmn * 10` for `.irr`.
   - fiat: `.usd` ticker → `1.0` in USD / `tmn` in IRT / `tmn*10` in IRR; other
     fiat `F` → `price(usd: 1/rates[F])`.
   - `apply(display:...) -> Double?` returns nil when a needed rate is absent
     (e.g. IRT display without `tmn`).
3. `MarketBuilder.build(settings, crypto: [CryptoQuote], tmn: Double?,
   fxRates: [String: Double], goldUSDPerGram: Double?, missing: Set<String>)
   -> MarketBuild` where `MarketBuild { rows: [MarketRow], unresolved: [String],
   omitted: [String], fatal: FetchOutcome? }` — the PRD §3 partial-failure policy:
   per-symbol row built (crypto rows get `dayChangePct` + `sparkline`, fiat/gold
   get price-only); a symbol whose kind's source failed is "omitted"; unresolved
   symbols collected; `fatal` is non-nil only when **zero** rows could be built
   (classify by which source is missing). `note = "Unknown: X" + "; Gold
   unavailable"` composition lives here too.
4. `MarketPriceFormatter` (pure) — `price(Double, currency) -> String` with
   abbreviation: `< 1M` full with thousands separators; `1M–1B` → `12.3M`;
   `≥ 1B` → `1.5B` (in the *display* currency's major unit); currency symbol
   prefix for USD (`$`), none for IRR/IRT (header carries the label); monospaced
   digit-friendly. `change(Double?) -> String` — `–` when nil, `+1.0%`/`-2.4%`,
   sign/color tier decided by the view.

**Tests:**
- Resolver: known crypto, `GOLD`, `CAD`→fiat, `XRPX`→unresolved; case
  normalization (`btc` → crypto).
- Converter: USD/IRT/IRR math incl. `IRR == IRT*10`; USD ticker = 1.0 / tmn;
  CAD in each display; nil rate → nil (not crash).
- Builder: all-ok; one unknown symbol → in `unresolved`, rows still built;
  gold source failed → gold omitted + note, others render, `fatal == nil`;
  display IRT with `tmn == nil` → `fatal == .unreachable`, zero rows.
- Formatter: `77,262`, `12.3M`, `1.5B`, `$` prefix only for USD, `–` for nil.

**Verification:** `xcodegen generate` + test command. Green.

## Phase 4 — FetchStatus + loader + agent block

**Goal:** the agent fetches, converts, writes `marketbox.json`, and records an
honest fetch-status.

**Files touched:**
- `native/Shared/FetchStatus.swift` — `FetchSource.marketbox`;
  `MarketLoaderError` cases in `FetchClassifier`; `FetchStatusCopy.line/hint`
  entries for all four outcomes.
- `native/Shared/MarketBoxSnapshot.swift` (append) — `HostMarketLoader.fetch(
  settings:) async throws -> MarketSnapshot`, with `MarketLoaderError`
  (`notConfigured`, `serverError(Int)`, `transport(String)`, `invalidPayload`).
- `native/DeckAgent/main.swift` — the marketbox block (pattern of
  main.swift:117-198).

**Steps:**
1. FetchStatus: add the source case; classify `MarketLoaderError`
   (`serverError` → `outcome(forStatusCode:)`, `transport` → `.unreachable`,
   `invalidPayload` → `.badResponse`); copy:
   - `.notConfigured` → "Add symbols in settings"
   - `.authOrTarget` → "Check the symbols"
   - `.unreachable` → "Can't reach the price sources"
   - `.badResponse` → "Unexpected market response"
   (and matching `hint` sentences).
2. `HostMarketLoader.fetch`:
   - parse + normalize `settings.symbols`; empty → throw `.notConfigured`;
   - resolve kinds via `MarketSymbolResolver`;
   - **fetch only what's needed** (PRD §3): CoinGecko `/coins/markets?...&price_change_percentage=24h&sparkline=true` if any crypto; gold-api `/price/XAU` if `GOLD`; Wallex `/v1/markets` if display ∈ {irr, irt}; open.er-api `/latest/USD` if any fiat ticker;
   - convert per-USD gold to per-gram (`÷ 31.1035`);
   - `MarketBuilder.build(...)`; if `fatal` → throw classified;
   - else build `MarketSnapshot` (rows in *display* order, `note` composed,
     `displayCurrency` = settings value) and return.
   - Timeout 10s per request, mirror `HostWeatherLoader`.
3. Agent block: `do { save; record(.ok) } catch { record(classified) }`; on
   `.notConfigured` record that and skip (never a request). Log snapshot name +
   row count only (never symbols/prices) — the repo's no-secrets logging rule.

**Tests:**
- `SharedTests/FetchStatusTests.swift` — classifier for `MarketLoaderError`
  (each case → expected outcome), `line`/`hint` non-empty for the four outcomes,
  `.ok` → nil.
- Builder-level coverage already in Phase 3 (loader itself stays thin, matching
  repo pattern — no URLProtocol stubbing).

**Verification:** `xcodegen generate` + test command. Green. (Optional manual:
`DeckAgent` run against live APIs writes `marketbox.json`; values cross-checked
against the probe numbers.)

## Risks

- **Wallex availability**: Iranian exchange; if it is down/blocked while display
  ∈ {IRR, IRT}, zero rows → `unreachable` chip + last-good stays. Accepted and
  honest (PRD §3). Display = USD needs no Wallex.
- **CoinGecko rate limits**: 1 `markets` call per 60s tick, well under the free
  limit (~30/min); a future `/coins/list` lookup stays a plan-time decision.
- **Symbol map coverage**: starts curated; unknown symbols are surfaced, not
  dropped silently (PRD §2).
