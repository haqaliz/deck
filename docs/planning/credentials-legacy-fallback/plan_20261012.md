# Implementation plan — credentials-legacy-fallback

**Slug:** `credentials-legacy-fallback` · **Branch:** `chore/credentials-legacy-fallback/aliz` · **Date:** 2026-10-12
**PRD:** `prd.md` · **Critique:** `critique.md`

Scope (locked with the user): remove the **fetch-time** legacy credential
fallback only; keep both migrations, `DeckSecret`, and the welded settings
fields they consume. Delete the already-dead `DeckSecret.fetchSource`.

Toolchain note: this is the xcodegen project, not a SwiftPM package — the
skill's `swift build` / `swift run` are replaced by `xcodebuild`. Any file
**added or deleted** requires `xcodegen generate` or it is silently not
compiled and the suite still reports success.

```bash
TEST='xcodebuild test -project native/Deck.xcodeproj -scheme DeckSharedTests \
  -derivedDataPath native/build.noindex CODE_SIGNING_ALLOWED=NO'
BUILD='xcodebuild -project native/Deck.xcodeproj -scheme DeckApp -configuration Release \
  -derivedDataPath native/build.noindex -allowProvisioningUpdates \
  -allowProvisioningDeviceRegistration build'
```

## Phase 2 — Remove the fallback from `CredentialsMigration.swift`

**Goal:** the decision table no longer consults the pre-accounts fields.

**Files touched**
- `native/Shared/CredentialsMigration.swift`

**Steps**
1. `credential(for:)` — delete the tail (`guard accountID(for: slot) == nil …`
   through `return legacy.token.isEmpty ? nil : legacy`); leave an explicit
   `return nil` after the `if let account` block. Trim the doc comment's
   "Only a slot with no selection at all consults the legacy field" sentence;
   keep the dangling-id paragraph.
2. `gate(_:unavailable:)` — collapse the `.off`/`.notConfigured` ternary to
   `return accountID(for: slot) == nil ? .off : .notConfigured`.
3. Delete the overload
   `gate(_:unavailableAccounts:unavailableLegacySecrets:)` entirely.
4. `openBoxUsesRemoteServer` — drop the legacy branch; return
   `account(for: .openbox).map { !$0.serverURL.isEmpty } ?? false`.
5. `prBoxGitHubIsOn` / `prBoxAzureIsOn` → `account(for: slot) != nil`; delete
   `providerIsOn(_:legacyEnabled:)`.
6. `legacyCredential(for:)` — **keep**; reword its doc comment from "the
   pre-accounts shape, for a Deck that was upgraded but never opened" to
   "the migrations' input".

**Verification**
```bash
$TEST
```
Phase 1's red tests go green; the untouched migration tests
(`CredentialsMigrationTests` migration cases, `DeckSecretsMigrationTests`,
`DeckSettingsSecretsTests`, `CredentialsWidgetReadsTests` migration cases) stay
green. The suite will **not compile yet** if Phases 2/3 land separately — see
dependencies.

**Dependencies:** Phase 1. Phase 3 must land in the same commit as this phase,
because removing the overload breaks the two call sites at compile time.

## Phase 5 — Full verification

**Goal:** prove the whole change end to end, including the grep guards the
CLAUDE.md traps name.

**Steps & verification**
1. **Full suite:** `xcodegen generate --spec native/project.yml && $TEST` —
   green, `Executed N test` with N>0.
2. **Release build:** `$BUILD` — succeeds.
3. **Extension reads stay token-free:**
   ```bash
   grep -rn "\.enabled\|serverURL" native/DeckWidgets/   # only account.* via the predicates
   ```
   Must show no legacy-field read; the three predicates turn on account fields.
4. **No fallback call sites remain:**
   ```bash
   grep -rn "legacyCredential\|unavailableLegacySecrets\|fetchSource" native \
     --include=*.swift | grep -v "CredentialsMigration.swift" | grep -v SharedTests
   ```
   The only `legacyCredential` hit is `CredentialsMigration.migrate` (the
   migration's input). `unavailableLegacySecrets` and `DeckSecret.fetchSource`
   are gone from production.
5. **Install + manual (behaviour change):** replace only the app bundle, quit
   Deck first (`pgrep -lf "MacOS/Deck$"`), then drive
   `/Applications/Deck.app/Contents/MacOS/DeckAgent` directly against a
   hand-written unmigrated `settings.json` (fields populated, no accounts) and
   confirm the credential widgets record `notConfigured`/`ok` rather than
   fetching — the accepted courtesy-expiry. Then open Deck and confirm the
   migrations still turn the fields into accounts (snapshot `ok`, account
   present in `settings.json`).
6. **Docs:** tick `ROADMAP.md:971-972`; correct `CLAUDE.md`'s "survive only for
   the one-way migration and a one-release fallback" sentence to say the
   fallback is gone and `DeckSecret` is migration-only.

**Dependencies:** Phase 4.
