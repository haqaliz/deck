## Phase 1 — AtomicFile helper (TDD)

**Goal:** one shared atomic-write helper in `Shared/`, proven by tests.

**Files:** `native/Shared/AtomicFile.swift` (new), `native/SharedTests/AtomicFileTests.swift` (new)

**Steps:**
1. `enum AtomicFile { static func write(_ data: Data, to url: URL) -> Bool }`
   — creates the parent directory, writes to `<name>.json.tmp.<UUID>` in the
   same directory, `FileManager.replaceItemAt(url, withItemAt: tmp)` (falling
   back to `data.write(to: url, options: .atomic)` when replace throws),
   removes the temp file if the replace fails; never throws — returns Bool.
2. Tests (TDD, `DeckSharedTests`):
   - writes to a `FileManager.default.temporaryDirectory`-scoped URL replace
     the target and `load()` decodes it;
   - **concurrent writers**: N threads × M writes of distinguishable payloads
     to one URL — the target is always valid (equals one of the payloads),
     never partial/empty;
   - fallback: force `replaceItemAt` failure (unwritable target dir) → returns
     false and target is unchanged;
   - no `.tmp.` leftovers after a successful write.

**Verification:** `xcodegen generate --spec native/project.yml && xcodebuild test -scheme DeckSharedTests -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO` — all green.

**Dependencies:** none.

## Phase 2 — Port every snapshot store + settings save to AtomicFile

**Goal:** no non-atomic snapshot write remains in the codebase.

**Files:** `native/Shared/ProcessSnapshot.swift:43`, `OpenCodeSnapshot.swift:112`,
`GitBoxSnapshot.swift:46`, `DevBoxSnapshot.swift:52`, `ClipBoxSnapshot.swift:50`,
`HomeBoxSnapshot.swift:61`, `ShipBoxSnapshot.swift:69`, `DeckSettings.swift:75`,
`native/DeckWidgets/LiveBoxWidget.swift:48` (HistoryStore)

**Steps:**
1. Replace `try? data.write(to: fileURL)` with
   `_ = AtomicFile.write(data, to: fileURL)` in all 8 Shared stores +
   `DeckSettings.save()` + `HistoryStore.save()` (keep the `guard let data =
   try? JSONEncoder().encode(...)` line — encode failures still bail).
2. Add one store round-trip test (save → load → equal) and a corrupt-file
   recovery test (garbage bytes at the URL → `load()` returns nil; next save
   heals it) for `ProcessSnapshotStore`.

**Verification:** existing `DeckSharedTests` still green (SmokeTests,
DecodeTests, all snapshot tests) + the new tests; `xcodebuild` Release build
of DeckApp passes.

**Dependencies:** Phase 1.

## Phase 3 — Single writer for processes.json

**Goal:** kill the F1 race at the source — the full agent stops writing the
process snapshot.

**Files:** `native/DeckAgent/main.swift`, `native/DeckApp/DeckApp.swift`

**Steps:**
1. Remove `sampleProcesses()` from the full-refresh path (line 48); the
   `--processes` mode (lines 23-27) stays the sole writer.
2. **Plan deviation (found during implementation):** the host app was a third
   writer (`DeckApp.swift:112-117` `refreshProcesses()`, called at launch +
   every 60s). Per the PRD "sole writer" contract it is removed too — the fast
   agent's RunAtLoad tick covers app-launch freshness, so the app call was
   redundant (`com.deck.agent.processes` has RunAtLoad per `installAgent`).
3. Manual run: `native/build/Build/Products/Release/DeckAgent --processes`
   twice (15s apart) → `processes.json` mtime/contents update; then run the
   plain `DeckAgent` → `processes.json` mtime unchanged (fast agent was not
   running), all other snapshots still written.

**Verification:** manual run above + full build green; DeckSharedTests green
(no parser changes — `PsParser` untouched).

**Dependencies:** Phase 2 (store already atomic).

## Phase 5 — Soak harness

**Goal:** a CI-fast script that stresses the write paths and asserts
no-crash + valid files.

**Files:** `scripts/soak.sh` (new)

**Steps:**
1. Script flow:
   - `xcodebuild` Release build (unsigned) — or reuse `native/build/…/DeckAgent`
     if present, else build.
   - **HOME-redirect the container**: `export HOME="$tmp"`, pre-create
     `Library/Containers/com.deck.app.widgets/Data/Library/Application
     Support/Deck/` (all stores + settings resolve under `$HOME` via
     `DeckSettings.containerDirectory` — the real user container is never
     touched).
   - Write a fixture `settings.json`: fixed HomeBox location, empty ShipBox
     repo/token, empty OpenBox server/token (those paths skip; weather may
     hit wttr.in — failure must be a skip, not a crash).
   - Loop: ≥ 200 full runs + ≥ 200 `--processes` runs, interleaved, with ≥ 50
     **overlapping launches** (start full, start `--processes` in the same
     instant, wait both) to exercise the race.
   - After every run: assert exit 0; assert every `*.json` in the fake
     container parses as JSON; at the end assert no `*.tmp.*` leftovers.
   - Print a summary line (`N runs, M overlaps, 0 failures`) and exit
     non-zero on any failure.
2. `set -euo pipefail`; no sudo; no network assertions beyond exit-0.

**Verification:** `scripts/soak.sh` runs green in ≤ a few minutes locally;
re-run with an injected failing payload (manual: corrupt one snapshot file)
proves it fails loudly.

**Dependencies:** Phases 2 + 3.
