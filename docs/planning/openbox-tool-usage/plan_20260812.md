## Phase 1 — OpenBoxToolsCore: pure tool aggregation (TDD, scratch SwiftPM package)

**Goal**: proven row→model mapping and top-N logic for the TOOLS section.

**Files touched**:
- `Package.swift` — scratch package: library `OpenBoxToolsCore` + test target
  `OpenBoxToolsCoreTests`.
- `Sources/OpenBoxToolsCore/ToolCount.swift` — `ToolCount: Codable, Equatable
  { let tool: String; let count: Int64 }` + pure `mapRows(_ rows: [[String: Any]]) -> [ToolCount]`
  (row.string("tool") + row.int64("count"), drops rows with nil tool,
  sorts by count descending) and `top(_ n: Int, from: [ToolCount]) -> [ToolCount]`
  (stable prefix).
- `Tests/OpenBoxToolsCoreTests/ToolCountTests.swift`.

**Steps** (TDD: failing test → green):
1. `ToolCount` + empty-rows mapping → `[]`.
2. Mapping: mixed rows (valid, nil-tool dropped, zero counts kept) → sorted
   desc.
3. `top(n)`: n > count → all; n = 0 → []; ties keep input order (stable).
4. Live shape parity: feed a hand-built `[[String: Any]]` mirroring
   `rows(db, toolsSQL)` output (tool as String, count as Int64) → expected
   [bash 7186, read 4169, edit 2098, …] fixture from the Phase-2 query.

**Verification**: `swift test` — all OpenBoxToolsCoreTests green.

**Dependencies**: none.

## Phase 2 — Snapshot + reader + remote degrade (native)

**Goal**: the snapshot carries tools; the agent produces them; remote mode
degrades to empty.

**Files touched**:

  gains `var tools: [ToolCount]`; add tolerant `init() {}` + `init(from:)`
  (`decodeIfPresent([ToolCount].self, forKey: .tools) ?? []` for the new key,
  plain `try c.decode` for the pre-existing keys) — the PR #8 pattern, so old
  `opencode.json` decodes.

  in `load()` via the ported `mapRows`.

  gain `tools: []` (the HTTP API doesn't expose tool events).

**Steps**:
1. Port Phase-1 logic into `OpenCodeReader` (a private `ToolCount` mapping,
   reusing the existing `rows()`/`int64()`/`string()` helpers).
2. Snapshot + tolerant init; remote aggregates.
3. `xcodebuild ... build` green.

**Verification**: build green; run the built `DeckAgent` binary directly and
confirm `opencode.json` now contains a `tools` array with the expected tools
(bash > read > edit on this machine) and the rest of the snapshot unchanged.

**Dependencies**: Phase 1.
