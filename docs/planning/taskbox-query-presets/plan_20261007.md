## Phase 1 — `WiqlPreset` + team literal (pure, TDD)

**Goal.** One pure type owns the three preset conditions and the
`'[Project]\Team'` literal, so the UI can only paste valid, composed clauses.

**Files touched**
- `native/Shared/WiqlPreset.swift` (new)
- `native/Shared/WiqlClause.swift` (`builtInCondition` gains a shared suffix)
- `native/SharedTests/WiqlPresetTests.swift` (new)
- `xcodegen generate` (new files are silently not compiled otherwise)

**Steps**
1. **RED.** In `WiqlPresetTests.swift`:
   - Every `WiqlPreset` condition validates (`WiqlClause.validate == nil`) with
     `team: nil` and with a `WiqlTeamContext` — probe P17/P21 shapes.
   - `.assignedToMe` is **byte-identical** to `WiqlClause.builtInCondition`
     (PRD §10.3), and that condition is `"[System.AssignedTo] = @Me AND " +
     WiqlClause.openStates` — pin the two against drift.
   - `.createdByMe` == `[System.CreatedBy] = @Me AND <openStates>`.
   - `.currentSprint` without a team == `[System.IterationPath] = @CurrentIteration AND <openStates>`;
     with `WiqlTeamContext(project: "ForesightManifold", team: "ForesightManifold Team")`
     == the P17 literal form. A team name with a space survives as-is.
   - `WiqlTeamContext.literal` escapes `'` as `''` (`Ali's Team` → `Ali''s Team`)
     and keeps `[Project]\Team` brackets.
   - Compositions through `WiqlClause.query(for:)` keep the project clause and
     ORDER BY outside (existing `WiqlClauseCompositionTests` pattern).
2. **GREEN.** Add `WiqlClause.openStates = "[System.State] NOT IN ('Closed', 'Removed', 'Done')"`;
   rewrite `builtInCondition` as `"[System.AssignedTo] = @Me AND " + openStates`.
   Create `WiqlPreset` (`CaseIterable`: `assignedToMe`, `createdByMe`,
   `currentSprint`; `title`; `condition(team: WiqlTeamContext?)`) and
   `WiqlTeamContext` (`project`, `team`, `literal`).
3. `xcodegen generate`; run the class, then the full scheme.

**Verification.** `-only-testing:DeckSharedTests/WiqlPresetTests` red first for
assertion reasons, then green; full suite > 1370, 0 failures.

**Dependencies.** None. Commit:
`feat(taskbox-query-presets): WiqlPreset conditions + team literal`.

## Phase 2 — 500 classification + teams parsing (pure parts TDD)

**Goal.** A bad team literal says why ("Check the query", probe P18/P19), and
the project's teams are readable for the picker.

**Files touched**
- `native/Shared/AzureDevOpsLoader.swift` (`WiqlResponse.interpret`, new
  `AzureTeamsParser` + `HostAzureTeamsLoader` beside the projects pair at
  `:657-718`)
- `native/SharedTests/AzureDevOpsParserTests.swift`

**Steps**
1. **RED** — `WiqlResponse.interpret(status:body:)`:
   - `400` with a message → `.queryRejected(message)`; `400` with no/empty
     message → `.queryRejected(nil)` (today's behavior, kept).
   - `500` with the P18 body (`VS402612: The macro '@CurrentIteration' is not
     supported without a team context.`) → `.queryRejected(message)`.
   - `500` with the P19 body (`… is not of the form '[project]\team'`) →
     `.queryRejected(message)`.
   - `500` with an HTML body or `{"other":1}` → `.serverError(500)`; `502`
     with a message-shaped body → `.serverError(502)`.
2. **GREEN.** `interpret`: `case 400` unchanged; `case 500` → parse the message,
   `queryRejected` when non-nil, else `serverError(500)`; everything else
   `serverError`. Comment the PRD §10.1 residual risk (an outage 500 that
   carries a message reads as a rejected query) and cite `probe.md`.
   `FetchClassifier`/`FetchStatusCopy` need no change — `.queryRejected` and
   `.unreachable` already exist.
3. **RED/GREEN** `AzureTeamsParser.parse(Data) -> [String]?`: names trimmed,
   empties dropped, sorted case-insensitively; `nil` for non-JSON or a missing
   `value`; `[]` for an empty list. Fixture bodies from probe F1/F3 plus
   malformed controls.
4. **GREEN** `HostAzureTeamsLoader.list(organization:token:project:)` — the
   `HostAzureProjectsLoader` shape (`:687-718`): `GET {orgBase}/_apis/projects/{projectSegment}/teams?api-version=7.1`,
   10s timeout, 200-only, host-app only.
5. Run the full scheme.

**Verification.** New `WiqlResponseTests`/`AzureTeamsParserTests` green; full
suite green and counts up.

**Dependencies.** None (parallel to Phase 1). Commit:
`feat(taskbox-query-presets): classify 500 macro errors + teams parser`.

4. Thread `settings.taskbox.team` at both call sites (`DeckAgent/main.swift:232`,

## Phase 4 — Settings UI: presets menu + team picker

apply), and the Team row appears only for a single-project account.

**Files touched**
- `native/DeckApp/DeckApp.swift` (`TaskBoxSettingsView` `:2306-2451`; call site
  `:184`)

**Steps**

   `WiqlPreset.allCases`; each item sets `draft = preset.condition(team: teamContext)`.
   Apply/Test unchanged; `onChange(of: draft)` still clears the Test line.
