# M11 — implementation plan (2026-11-17)

One milestone, four phases. Slices 1–3 are built; phase 4 is the installed
verification.

## Phase 1 — Credentials and settings (built)

- [x] `CredentialKind` `.elastic` / `.grafana`; display names, symbols, search
      aliases (`kibana`, `prometheus`, `metrics`).
- [x] `CredentialAccount.baseURL` + `uiURL`, tolerant decode/encode, included
      in `credentialFingerprint` so editing a URL invalidates Verify.
- [x] Slots `logboxElastic` / `metricboxGrafana` → sources `logbox` /
      `metricbox`; `legacySecret` made optional (the infra slots have none).
- [x] `ResolvedCredential` carries both URLs; the gate refuses an Elastic or
      Grafana account with no base URL.
- [x] `CredentialVerifier`: Elastic `_cluster/health` + `logs-manifold-*`
      count; Grafana authenticated `/api/datasources` + `/api/org`.
- [x] Credentials detail form: Elasticsearch URL + optional Kibana URL;
      Grafana URL; provider-specific token titles.
- [x] `LogBoxSettings` / `MetricBoxSettings`, persisted and tolerant; hosts,
      faces, windows, text mode, rate, colours.
- [x] `CredentialsCopy`, `FetchStatus` sources, classifier and copy.

## Phase 2 — LogBox (built)

- [x] `LogBoxSnapshot` + store (`logbox.json`), tolerant decode.
- [x] Query builders: fast 15m counts and error services/templates; slow 24h
      trend with ~48 buckets; newest five errors.
- [x] `ElasticLogParser` (counts, trend, recent lines) and `InfraDate`.
- [x] `LogBoxLoader`: direct ES, `ApiKey` auth, 10s timeout, 15-minute slow
      cache, partial-failure rule, service filter.
- [x] Widget face: counts, Path-based trend bars (no Swift Charts), services,
      templates, raw modes, Kibana deep links; all three sizes.
- [x] Agent tick + host refresh method; fetch status and stale age.
- [x] Settings tab: account, environment, face, text mode, windows, accent.

## Phase 3 — MetricBox (built)

- [x] `MetricBoxSnapshot` + store (`metricbox.json`), host/agent/alert models.
- [x] Datasource discovery from `/api/datasources` (default Prometheus), no
      hard-coded uid.
- [x] One instant query for CPU/RAM/disk/last-seen/uptime/GPU/VRAM/temp/watts/
      kWh, one for top agents, one for firing alerts, optional 24h CPU trend.
- [x] `GrafanaDSQueryParser`, `GrafanaDatasourceParser`, `GrafanaAlertParser`.
- [x] `MetricBoxSort.worstFirst` (silent first, then pressure) and monthly cost.
- [x] Widget faces: fleet, single host, power, top agents, alerts; all sizes.
- [x] Agent tick + host refresh method; fetch status and stale age.
- [x] Settings tab: account, face, host picker, hide list, rate, windows, accent.

## Budgets and traps

- Elastic fast path every 60s (~10ms); 24h path at most every 15 minutes
  (~4.4s) and reused in between.
- Grafana instant + agents + alerts ≈ 1–2s; the single-host trend is one
  extra range query with 24 points.
- No Swift Charts in either face.
- WidgetKit only hands URLs to the app; `DeckLink.webURL` filters them and
  `DeckAppDelegate` forwards them.
- New source files require `xcodegen generate` or they are silently not
  compiled.
- The extension version bump is load-bearing: without it the new widgets never
  appear in the gallery.
