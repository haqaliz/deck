# GitBox — Implementation Plan

Date: 2026-08-10. Source: `docs/planning/gitbox/prd.md`. Slug: `gitbox`.
Branch: `feat/gitbox/aliz` (worktree `.claude/worktrees/feat-gitbox`).

## Phase 1 — GitBoxCore: models, parser, math (TDD)

**Goal**: pure, tested core for day-window counting, streak (grace rule), and
window labels — no subprocesses.

**Files touched**:
- `Sources/GitBoxCore/Models.swift` — public structs.
- `Sources/GitBoxCore/GitLogParser.swift` — day-line counting.
- `Sources/GitBoxCore/GitMath.swift` — streak + 14-day window.
- `Sources/GitBoxCore/Formatters.swift` — count/short-name formatting.
- `Tests/GitBoxCoreTests/GitLogParserTests.swift`, `GitMathTests.swift`,
  `FormatterTests.swift`.
- `Package.swift` — `GitBoxCore` library product + target + `GitBoxCoreTests`
  test target.

**Steps** (TDD: write the failing test, make it green):
1. Models: `RepoCommits { shortName, path, todayCount }`,
   `DayCommitCount { day: String, count: Int }` (both `Equatable`).
2. `GitLogParser.dayCounts(from: String) -> [String: Int]` — counts
   `yyyy-MM-dd` lines; skips blank/garbage; parser keeps everything, windowing
   happens in math.
3. `GitMath.daysBack(_ n: Int, today: String) -> [String]` — last n calendar
   day labels ending at `today` (inclusive), oldest first.
4. `GitMath.bucket(counts: [String: Int], window: [String]) -> [Int]` —
   ordered 14-bucket array from raw counts (this is where the
   fetch-15-days/keep-14 gap closes).
5. `GitMath.streak(counts: [String: Int], today: String, yesterday: String) -> Int` —
   grace rule: if today is empty, count consecutive days with ≥1 commit ending
   at yesterday; if today has commits, run includes today; no commits → 0.
6. `GitFormatters.commitCount(Int) -> String`, `GitFormatters.shortName(path: String) -> String`.

**Tests**: parser (multi-line, duplicates per day, garbage, empty); window
(14 labels, today last); bucket (order preserved, out-of-window days dropped);
streak (today empty → yesterday run, today full → includes today, gap breaks
run to 0, single commit yesterday → 1); formatters (count grouping, short name
of `/a/b/repo` → `repo`).

**Verification**: `swift test` (all targets, GitBoxCoreTests green).

**Dependencies**: none.

## Phase 2 — GitBox scaffold + loader + store

**Goal**: copy the NetBox shell, add the settings struct and the git loader,
wire the store (background sampling).

**Files touched**:
- `Package.swift` — `GitBox` executableTarget with `GitBoxCore` dependency.
- `Sources/GitBox/AppMain.swift` — copy NetBox's, `GitBox`-ify (bundle id,
  executable name, entitlements untouched).
- `Sources/GitBox/Settings.swift` — `GitBoxSettings`: `showChart=true`,
  `showRepos=true`, `repoCount=5`, `barColor` (default accent-ish blue),
  `todayColor` (default orange), `scanDepth=4`, `repoPaths=[]`,
  `refreshSeconds=30`, `launchAtLogin=false`. SettingsStore at
  `~/Library/Application Support/GitBox/settings.json`, LaunchAgent
  `com.gitbox.widget`.
- `Sources/GitBox/GitMetrics.swift` — `GitMetricsLoader`:
  - `discoverRepos(paths:depth:) -> [URL]` — walk each configured path (default
    `~/dev` when `repoPaths` empty), up to `scanDepth` levels, collecting dirs
    containing `.git` (file or dir — covers worktrees/submodules). Cheap walk;
    repos cached per refresh.
  - `sample(repos:) -> [RepoCommits]` — for each repo run
    `/usr/bin/env git -C <path> log --pretty=%ad --date=format-local:%Y-%m-%d --since=15.days.ago`
    via `Process` (BatBox ioreg pattern); `GitLogParser` → counts; aggregate
    per-repo `todayCount`; skip repo on any failure (exit ≠ 0, timeout, garbage).
  - Discovery failure / zero repos → empty result (empty state upstream).
- `Sources/GitBox/MetricsStore.swift` — ObservableObject; publishes
  `dayCounts: [DayCommitCount]` (14), `todayCount: Int`, `streak: Int`,
  `repos: [RepoCommits]`, `hasRepos: Bool`, `isLoaded: Bool`. `start()`:
  first sample immediately, then Timer at `settings.refreshSeconds`
  (10/30/60). **Deviation (documented in PRD)**: sample runs on a background
  queue; results marshalled to MainActor. History is the 14-day window — no
  rolling 90-sample buffer.

**Verification**: `swift build` green; `swift test` green; `swift run GitBox`
shows an empty card (no crash) with `~/dev` discovery on this machine.

**Dependencies**: Phase 1.

## Phase 3 — Front face

**Goal**: the card shows today/streak, the 14-day chart, and active repos.

**Files touched**: `Sources/GitBox/ContentView.swift` (front face only;
settings face stubbed with a placeholder button).

**Steps**:
1. Header: `TODAY` + `STREAK` labels with dot colors (barColor/todayColor),
   gear button right — NetBox `RateLabel` pattern.
2. Bar chart: `Chart` with `BarMark` per `DayCommitCount` (x = day label,
   y = count), today's bar in `todayColor`, others `barColor`; X axis hidden,
   faint Y gridlines (shell style); height 130pt.
3. REPOS list: `REPOS` header + `CustomScrollView` (copied from NetBox) —
   rows: short name (disambiguated by relative path when names repeat) +
   today count; capped at `repoCount` rows, height grows with rows (NetBox
   pattern, cap ~6 rows); zero-active repos → "No commits today" line.
4. Empty state: no repos discovered → single line "No git repos found" +
   "Add paths in settings" (BatBox no-battery pattern).
5. Wire `PanelHeightKey` / `reportHeight()` / flip exactly as NetBox.

**Verification**: `swift build -c release`; `swift run GitBox`; `CGWindowList`
bounds = content height, corners rounded; visual diff vs NetBox shell behavior.

**Dependencies**: Phase 2.

## Phase 4 — Back face (settings)

**Goal**: flip-card settings with the paths list editor.

**Files touched**: `Sources/GitBox/ContentView.swift` (settings face frame),
`Sources/GitBox/SettingsView.swift`.

**Steps**:
1. CHART: show-chart toggle, bar color picker, today color picker
   (`metricRow` pattern).
2. REPOS: show-repos toggle; repo count stepper 1–10 (default 5); scan depth
   stepper 1–10 (default 4); **paths list editor** — one TextField + Add
   button, rows with path + × remove button; empty list = default `~/dev`
   scan (shown as hint text).
3. REFRESH: segmented picker 10/30/60s (default 30).
4. STARTUP: "Open at startup" toggle (LaunchAgent binding), hidden when
   `NativeWidgetDetector.isRegistered()`.
5. Store changes from the editor re-trigger a scan immediately (paths/depth
   change → next sample uses them; listen via `settings.$settings`).

**Verification**: `swift run GitBox --debug-flip`; add/remove a path, change
depth/count → restart → persisted in settings.json; chart/list reflect the
new repo set.

**Dependencies**: Phase 2 (settings already exist), Phase 3.
