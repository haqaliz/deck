## Phase 1 — DevBoxCore: parsers (TDD, scratch SwiftPM package)

**Goal**: pure, tested parsers for `lsof -F` output and `docker ps`/`stats`
lines — no subprocesses, no timers.

**Files touched**:
- `Package.swift` — scratch package: library `DevBoxCore` + test target
  `DevBoxCoreTests`.
- `Sources/DevBoxCore/Models.swift` — `PortInfo { command, host, port }`,
  `ContainerInfo { name, image, status, cpuPercent: Double?, memPercent: Double? }`,
  `DockerState { unavailable, noContainers, running }` (all `Equatable`).
- `Sources/DevBoxCore/LsofParser.swift` — `parse(_ raw: String) -> [PortInfo]`.
- `Sources/DevBoxCore/DockerParser.swift` —
  `parseContainers(psOutput:statsOutput:) -> ([ContainerInfo], DockerState)`,
  `parsePercent(_ s: String) -> Double?`.
- `Sources/DevBoxCore/Formatters.swift` — `portLabel(host:port:)`,
  `percentString(_ value: Double?)`.
- `Tests/DevBoxCoreTests/LsofParserTests.swift`, `DockerParserTests.swift`,
  `FormatterTests.swift`.

**Steps** (TDD: failing test → green):
1. Models + `LsofParser`: iterate lines; `p<pid>`/`c<command>`/`n<host>:<port>`
   token stream (a `p` starts a new process block; `c` updates command; an `n`
   emits a row). Port = substring after the last `:`. Skip garbage rows.
2. Dedupe by `(command, name)` keeping the first (IPv4+IPv6 collapse); sort by
   numeric port ascending, then command.
3. `DockerParser.parseContainers`: split ps rows on `|` (name|image|status —
   `{{.Names}}` first segment when comma-joined); stats rows name|cpu%|mem%;
   **join rule**: ps is the identity source; stats-only names dropped; ps row
   missing from stats → `nil` cpu/mem. State: ps output empty → `noContainers`
   (caller maps non-zero exit → `unavailable`).
4. `parsePercent`: strip `%` and whitespace → `Double`; garbage → nil.
5. `Formatters`: `portLabel("127.0.0.1", 6379) → "127.0.0.1:6379"`,
   `portLabel("*", 7000) → "*:7000"`, `percentString(nil) → "—"`,
   `percentString(2.312) → "2.3%"`.

**Tests**: lsof (real captured sample from this machine: rapportd *:63100
IPv4+IPv6 dedupe, redis 127.0.0.1:6379, `[::1]` brackets, garbage lines,
empty); docker (normal rows, missing stats, stats-only dropped, empty ps,
swarm comma-names, `0.05%`/`2.31%`/garbage percents).

**Verification**: `swift test` — all DevBoxCoreTests green.

**Dependencies**: none.

  subprocess runners (Process + Pipe, the `gitLogDays` pattern at
