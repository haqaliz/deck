## Phase 1 — HomeBoxCore scratch package (TDD)

**Goal**: pure logic — wttr.in j1 parsing, WW-code → SF Symbol mapping, zone
label derivation — proven by tests before any wiring.

**Files touched**:
- `HomeBoxCore/Package.swift` — scratch package: library `HomeBoxCore` + test
  target `HomeBoxCoreTests`.
- `HomeBoxCore/Sources/HomeBoxCore/WeatherModels.swift` — `WeatherSnapshot`-shaped
  value types: `WeatherCondition` (code: Int?, desc: String, tempC: Double?,
  tempF: Double?, feelsLikeC/D: Double?, humidity: Double?, windDir: String,
  windKmph: Double?), `WeatherDay` (date, maxTempC/F, minTempC/F, desc), and
  `ParsedWeather` (location, current, days, sourceDate).
- `HomeBoxCore/Sources/HomeBoxCore/WttrParser.swift` — `parse(j1Data: Data) -> ParsedWeather?`:
  decodes the j1 shape with **all-numeric fields as strings** (temp_C, temp_F,
  FeelsLikeC/F, humidity, windspeedKmph, weatherCode), trims `weatherDesc`
  values (they carry trailing spaces, verified in the live payload), resolves
  `nearest_area[0]`, extracts `weather[]` (3 days) maxtemp/mintemp/desc;
  tolerant of missing keys.
- `HomeBoxCore/Sources/HomeBoxCore/WeatherIcon.swift` — `symbol(for code: Int?) -> String`
  mapping WW codes → SF Symbols (113 sun.max, 116 cloud.sun, 176 cloud.drizzle,
  …), **unknown/nil → "cloud" fallback**.
- `HomeBoxCore/Sources/HomeBoxCore/ZoneRows.swift` — `zoneRows(identifiers: [String], at date: Date) -> [ZoneRow]`
  where `ZoneRow` = (label, timeString HH:MM); `"local"` → `TimeZone.current`;
  invalid identifiers dropped; max 3; label = last path component of the
  identifier (e.g. `Europe/Amsterdam` → "Amsterdam").
- `HomeBoxCore/Tests/HomeBoxCoreTests/` — parser, icon, zone tests.

**Steps** (RED → GREEN → REFACTOR):
1. `WeatherModels` + `WttrParser` against the **real captured j1 payload**
   (fixture JSON file saved from the 2026-08-14 fetch): temps parsed from
   strings, desc trimmed, unknown numeric field missing → nil, empty `weather[]`
   → empty days.
2. `WeatherIcon`: known codes, unknown code → cloud, nil → cloud.
3. `ZoneRows`: local + UTC defaults, invalid dropped, 4+ identifiers → first 3,
   label derivation, HH:MM formatting in each zone.

**Verification**: `swift test` in `HomeBoxCore/` — all green.

**Dependencies**: none.

## Phase 2 — Shared data layer

**Goal**: snapshot + store + host loader + settings struct, compilable in all
three targets.

**Files touched**: `native/Shared/HomeBoxSnapshot.swift` (new),
`native/Shared/DeckSettings.swift`.

**Steps**:
1. `HomeBoxSnapshot` (Codable, Equatable: `writtenAt: Date`, `location: String`,
   `condition: WeatherCondition?`, `days: [WeatherDay]`) + `HomeBoxSnapshotStore`
   (file `weather.json` in `DeckSettings.containerDirectory`, load/save copied
   from `GitBoxSnapshotStore`).
2. `HostWeatherLoader.fetch(location: String) async throws -> HomeBoxSnapshot` —
   URL `https://wttr.in/{location}?format=j1` (location empty → `https://wttr.in/?format=j1`),
   using the `RemoteOpenCodeLoader` transport pattern (async `URLSession.shared.data`,
   status-code mapping to a `WeatherError` enum, timeout ~10s), body through the
   ported `WttrParser`.
3. `HomeBoxSettings` in `DeckSettings.swift` with tolerant decode (PR #8
   pattern): `location = ""`, `unitsFahrenheit = false`, `timezoneIDs = ["local", "UTC"]`,
   `showForecast = true`, `showZones = true`.
4. `DeckSettings`: add `var homebox = HomeBoxSettings()`.

**Verification**: `xcodegen generate` + `xcodebuild` Release build green.

**Dependencies**: Phase 1 (ported logic).

## Phase 3 — Agent + app data wiring (with empirical probe)

**Goal**: snapshot flows end-to-end; the wttr.in fetch from the agent is probed
for real.

**Files touched**: `native/DeckAgent/main.swift`, `native/DeckApp/DeckApp.swift`.

**Steps**:
1. `DeckAgent/main.swift`: after clipbox — `if let home = try? await HostWeatherLoader.fetch(location: settings.homebox.location) { HomeBoxSnapshotStore.save(home) }`
   — **always write on success** (ClipBox precedent, PRD), skip on failure so
   `writtenAt` ages into the stale affordance.
2. **Probe**: run the built `DeckAgent` binary directly from the terminal, then
   inspect `weather.json` — must contain a real location name + current temp +
   3 forecast days. If the fetch fails, check URL construction + network from
   the CLI context (the agent is unsandboxed; should pass).
3. `DeckApp.swift`: `refreshHomeBox()` (host-side, mirrors `refreshGitBox`),
   wired into `onAppear` + 60s timer; sidebar `DeckWidget.homebox` case
   (title "HomeBox", systemImage "cloud.sun") — tab view placeholder.

**Verification**: probe passes; `xcodebuild` Release green.

**Dependencies**: Phase 2.

## Phase 4 — Widget front face

**Goal**: the card renders weather + world clock from the snapshot.

**Files touched**: `native/DeckWidgets/HomeBoxWidget.swift` (new, copy of
`GitBoxWidget.swift`), `native/DeckWidgets/DeckWidgets.swift`.

**Steps**:
1. `HomeBoxEntry` (date, available, stale, location, condition, days, zoneRows,
   settings) + `HomeBoxProvider` (placeholder/getSnapshot/getTimeline, 60s
   policy; staleness windows per PRD: <5 min fresh, 5–30 min stale hint,
   >30 min unavailable — `GitBoxWidget.swift:50` pattern extended).
2. `HomeBoxWidget` (kind `HomeBoxWidget`, small/medium/large) + register in
   `DeckWidgets.swift` bundle.
3. Views:
   - small: location (secondary, tracked) + WW icon + big temp (monospaced
     digits) + feels-like + local time row.
   - medium: + timezone rows (dot + label + HH:MM) from `ZoneRows`.
   - large: + 3-day forecast strip (day label, icon, max/min) + "wttr.in"
     attribution + stale time hint on the location row.
   - **timezone rows always render even when weather is unavailable** (PRD);
     unavailable card otherwise; `containerBackground` root (shell invariant).
4. `HomeBoxSnapshotStore.load()` + `DeckSettings.load().homebox` in provider;
   unit choice (C/F) applied at render.

**Verification**: `xcodegen generate` + build + install to `/Applications/`,
re-add from the gallery; three sizes show live weather + clocks.

**Dependencies**: Phase 3.
