# Implementation Plan — MarketBox live coin lookup (2026-09-05)

**PRD:** `prd.md` (14 sections, self-critiqued: 2 red / 5 amber).
**Branch:** `feat/marketbox-coin-lookup/aliz` · **Target release:** v1.40.

## A note on the plan template

The `deck-plan` skill's template still describes the pre-M2 shell — `Package.swift`,
`Sources/<Widget>/`, `swift test`, `swift run <Widget> --debug-flip`, panel
height/corner-mask checks. **None of that exists in Deck today**: floating window
widgets were removed in M2 (`ROADMAP.md`), the project is xcodegen, and there are
no panel invariants to check. This plan uses the real commands from `CLAUDE.md`.

```bash
# after any new source file (xcodegen enumerates files at generation time —
# a new test file is otherwise silently not compiled and the suite still passes)
xcodegen generate --spec native/project.yml

# the per-phase green gate
xcodebuild -project native/Deck.xcodeproj -scheme DeckSharedTests \
  -configuration Debug -derivedDataPath native/build.noindex test

# the release build, only in phases 6-7
xcodebuild -project native/Deck.xcodeproj -scheme DeckApp -configuration Release \
  -derivedDataPath native/build.noindex -allowProvisioningUpdates \
  -allowProvisioningDeviceRegistration build
scripts/lsclean.sh          # after EVERY release build
```

**Every phase ends green**: the suite passes, and phases 6-7 also build.

## Dependency graph

```
P1 (ticker model + migration) ─┬─> P2 (builder + loader) ─┐
P3 (sub-cent formatter) ───────┘                          ├─> P6 (settings UI) ─> P7 (release)
P4 (search parser + policy) ──> P5 (host loader) ─────────┘
```

P3 and P4 depend on nothing and can be done in any order. P6 is the only phase
that touches UI, and it is the only one that cannot be proven by the test suite
alone.

## Phase 1 — `MarketTicker` and the migration

**Goal.** Settings hold the CoinGecko id, and no existing user loses their list.

**Files.** `native/Shared/MarketBoxCore.swift`, `native/Shared/DeckSettings.swift`,
`native/SharedTests/MarketTickerTests.swift` (new), `native/SharedTests/DecodeTests.swift`.

**Steps.**
1. **RED** — `MarketTickerTests`: `tickerList` wins; `[String]` maps through the
   curated table (`BTC` → `bitcoin`/`Bitcoin`); an unknown symbol survives with
   an empty `coinID`; the legacy free-text `symbols` string still works; none →
   the four defaults; dedupe by symbol; cap at 12; **and a round-trip asserting
   `tickerList` actually encodes** (the hand-written `CodingKeys` trap —
   a forgotten case compiles, decodes as absent and never encodes).
2. Add `MarketTicker` (`symbol`, `name`, `coinID`, `rank: Int?`) to
   `MarketBoxCore.swift`, with `kind` **derived** from `coinID`/`GOLD`, never stored.
3. Add `MarketTickerMigration.tickers(fromSymbols:)` — pure, the curated map's
   new and only job besides the Popular list.
4. `MarketBoxSettings`: add `tickerList`, add the `CodingKeys` case, implement
   the four-step tolerant decode (PRD §6), and **clear the legacy `tickers` key
   on encode** so a downgrade costs the MarketBox list alone rather than throwing
   inside `init(from:)` and resetting every setting via `DeckSettings.load()`'s
   catch-all fallback.
5. **GREEN**, then extend `DecodeTests` with a settings-file fixture carrying the
   old `tickers` array.

**Verification.** `xcodegen generate` (new test file!) then the suite. Plus a
one-off decode of the *real* `settings.json` from the container, asserting the
four live tickers survive with ids attached.

**Depends on.** Nothing.

## Phase 2 — The builder and loader stop resolving symbols (C2, C3)

**Goal.** A picked coin outside the curated 43 actually prices; a retired id
reads as "no data", not "the source is down"; an empty `ids=` is never requested.

**Files.** `native/Shared/MarketBoxCore.swift`, `native/Shared/MarketBoxSnapshot.swift`,
`native/DeckAgent/main.swift`, `native/SharedTests/MarketBoxCoreTests.swift`,
`native/SharedTests/MarketBoxSnapshotTests.swift`.

**Steps.**
1. **RED** — builder tests for the three crypto states: `[:]` (no crypto
   tickers, says nothing) · `nil` (attempted and failed → `Crypto unavailable`)
   · populated-but-id-absent (→ `No data: XYZ`). Plus: a coin outside the
   curated 43 prices normally — the test that would have caught C2.
2. **RED** — empty-ids guard: no crypto tickers → no request; a crypto ticker
   with a blank `coinID` → no request. (Measured: `ids=` empty answers **200 with
   the top 100 coins, 83.6 KB**, which would render as the user's list.)
3. Change `MarketBuilder.build(symbols:)` → `build(tickers:)`; read kind off the
   ticker; add the `noData` bucket to `MarketBuild` and its note wording;
   keep `collapse` behaviour unregressed.
4. Change `MarketBoxSnapshot.load` to compute `needsCrypto/needsGold/needsFiat`
   from the tickers, and `fetchCrypto(ids:)` to take ids and return `[]` without
   building a request when the list is empty.
5. Update the `DeckAgent` call site.
6. **GREEN.** `MarketSymbolResolver.kind(for: String)` now survives only for the
   migration table — assert that with a comment, not a deletion.

**Verification.** Suite green, including the existing MarketBox tests unchanged
in intent. `grep -n "kind(for:" native/Shared/MarketBoxSnapshot.swift` returns
nothing.

**Depends on.** P1.

## Phase 3 — Sub-cent prices stop reading as zero

**Goal.** SHIB/PEPE/BONK — already shipped and already broken — render a real price.

**Files.** `native/Shared/MarketBoxCore.swift`,
`native/SharedTests/MarketBoxCoreTests.swift`.

**Steps.**
1. **RED** — the three live values measured on 2026-09-05
   (`5.47e-06` → `$0.00000547`, `3.57e-06` → `$0.00000357`,
   `3.27e-06` → `$0.00000327`), `1.752e-05` → `$0.0000175`, plus the
   `1e-9 / 0.01 / 1 / 1e3 / 1e6 / 1e9` boundaries, zero → `$0.00`, and the
   large-value cases (`$77,850`, `15.6B`, `$1.75`) **unchanged**.
2. Add the two new branches to `MarketPriceFormatter.price`: 3 significant
   digits for `1e-9 ..< 0.01`, 2-significant-digit exponential below `1e-9`
   (thirteen leading zeros do not fit a widget row). Everything `≥ 0.01`
   untouched.
3. **GREEN.**

**Verification.** Suite. This phase is pure and needs no build.

**Depends on.** Nothing.

## Phase 4 — Search parser and request policy (pure)

**Goal.** Turn `/search` into typed rows, and pin the rules that keep the picker
off the agent's quota.

**Files.** `native/Shared/CoinSearch.swift` (new),
`native/SharedTests/CoinSearchTests.swift` (new),
`native/SharedTests/Fixtures/coingecko_search_pepe.json` (new, captured live).

**Steps.**
1. Capture the fixture from the live endpoint (`?query=pepe`, 25 coins, 10.5 KB)
   and trim it to the `coins` array plus one sibling section, so the test proves
   `exchanges`/`nfts` are ignored.
2. **RED** — `CoinSearchParser`: 25 hits, **server order preserved** (not
   re-sorted — `/search` is already rank-ordered and its ordering is not a
   documented guarantee, so preserving is honest), `market_cap_rank: null`
   tolerated, non-coin sections ignored, malformed → `nil`, `[]` → `[]`.
3. **RED** — `CoinSearchPolicy`: min length 2, 600 ms debounce, the 2 s floor
   between requests, cache hit/miss by normalized query, and 429 → a busy state
   with **no** auto-retry.
4. **GREEN** for both.

**Verification.** `xcodegen generate` (two new files) then the suite.

**Depends on.** Nothing.

## Phase 5 — `HostCoinSearchLoader`

**Goal.** Join the parser and policy to `URLSession`, host-app-side only.

**Files.** `native/Shared/CoinSearch.swift`.

**Steps.**
1. Add `HostCoinSearchLoader.search(query:)` beside the other `Host*Loader`s:
   10 s timeout, percent-encoded query, **429 detected by status code** and
   surfaced as its own typed error (not lumped with `serverError`).
2. Assert by construction that it is never called from `DeckAgent` or the
   extension: `grep -rn "HostCoinSearchLoader" native/DeckAgent native/DeckWidgets`
   must stay empty — added to the phase's verification, and worth a comment at
   the declaration.

**Verification.** Suite green (the loader itself is thin; the parser and policy
carry the tests). One manual live call to confirm the 200 path, and one
back-to-back burst to confirm the 429 path is classified — run **once**, not in
a loop, because the quota is shared with the agent.

**Depends on.** P4.

## Phase 6 — The settings tab (the only UI phase)

**Goal.** Twelve fixed slots become a reorderable add/remove list with a search sheet.

**Files.** `native/DeckApp/DeckApp.swift`.

**Steps.**
1. **Reordering gate, first, before anything else is built** (C6). Slot order was
   display order for free; the list must not lose it. Try `.onMove` inside the
   settings `Form` on macOS; if it does not work, fall back to explicit ↑/↓
   buttons per row. **Do not defer this to polish** — a list whose order cannot
   be changed is a regression against the twelve slots it replaces.
2. Replace the `ForEach(0..<maxCount)` slot pickers with the ticker list: symbol,
   name, remove button. **No rank in the list** (C5) — a rank stored at pick time
   goes stale.
3. Build the **Add Ticker…** sheet: a search field bound through
   `CoinSearchPolicy` (debounced, cached, one in-flight task, previous
   cancelled); results as `#rank  SYMBOL  Name` with rank fresh from the
   response; **Popular** = the curated 43 when the query is empty, zero network,
   works offline; **Fiat & Gold** sections from the existing curated lists.
4. Duplicate refusal (C1): adding a symbol already in the list shows
   *"PEPE is already in your list."* — never a silent drop.
5. Disable **Add Ticker…** at 12 with "12 is the maximum".
6. Failure copy: 429 → *"Search is busy — try again in a moment."*; offline →
   *"Search needs a connection."*; both leave existing rows and the snapshot alone.
7. Point `FetchStatusCaption(clearOn:)` at the `tickerList` ids (C4) — otherwise
   the fetch-error sentence stops clearing when the user fixes their list.

**Verification.** Release build + `scripts/lsclean.sh`, install to
`/Applications`, and drive the real app: add a coin **outside the old 43**
(e.g. `PURPE`), confirm it appears in the list, then **quit Deck** (a running
Deck overwrites both `settings.json` and the snapshot with its in-memory copy —
`pgrep -lf "MacOS/Deck$"` is the check) and run
`/Applications/Deck.app/Contents/MacOS/DeckAgent` directly. Assert the new coin
has a row with a non-zero price in `marketbox.json`. Also exercise: duplicate
refusal, the 12 cap, reorder, remove-to-empty, and offline (Wi-Fi off) for both
the sheet and the list.

**Depends on.** P1, P4, P5.

## What could still go wrong

1. **`.onMove` in a macOS `Form`** — mitigated by making it phase 6 step 1 with a
   defined fallback, rather than discovering it at the end.
2. **The shared quota during P6's manual testing.** Testing the picker burns the
   same budget the agent uses; if MarketBox goes stale while testing, that is the
   429 path working as designed, not a bug. Wait 60 s.
3. **A fixture that drifts.** `coingecko_search_pepe.json` is a snapshot of a
   live ranking; the test must assert *structure and order preservation*, never
   that `pepe` is rank 56 forever.
