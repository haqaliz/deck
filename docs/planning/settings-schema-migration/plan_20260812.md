## Phase 1 — SettingsCore: tolerant decoders (TDD, scratch SwiftPM package)

**Goal**: proven `init(from:)` decode logic for all five settings structs —
missing keys fall back to defaults, present values decode identically, type
mismatches still throw.

**Files touched**:
- `Package.swift` — scratch package: library `SettingsCore` + test target
  `SettingsCoreTests`.
- `Sources/SettingsCore/Models.swift` — mirror structs of the five settings
  types (`OpenBox`, `NetBox`, `BatBox`, `GitBox`, `DevBox`) with the exact
  field set/defaults from `DeckSettings.swift:109-152`, plus a plain Codable
  `RGBA` mirror (no SwiftUI/AppKit imports — pure Foundation).
- `Sources/SettingsCore/Decode.swift` — for each mirror: `init() {}` +
  `init(from:)` with `decodeIfPresent` per key (the LiveBoxSettings pattern,
  `DeckSettings.swift:92-106`); `serverURL` via `decodeIfPresent(String.self)`
  (missing/null → nil, present → value); `repoPaths` via
  `decodeIfPresent([String].self) ?? []`.
- `Tests/SettingsCoreTests/DecodeTests.swift`.

**Steps** (TDD: failing test → green):
1. Mirror structs + naive synthesized Codable → write failing tests:
   - **missing-key fixture** (old schema, e.g. a DevBox-less JSON) → all
     defaults, including colors; GitBox `repoPaths == []`.
   - **full fixture** → exact values round-trip (Equatable against a
     hand-built instance).
   - **null `serverURL`** → nil; **missing `serverURL`** → nil.
   - **type mismatch** (e.g. `"showChart": "yes"`) → throws (unchanged
     semantics).
   - **unknown extra keys** → ignored, decodes.
   - **encode round-trip**: `JSONDecoder(encode(x)) == x` for a full instance.
2. Implement the five `init(from:)`s → tests green.

**Verification**: `swift test` — all SettingsCoreTests green.

**Dependencies**: none.
