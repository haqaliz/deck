# Plan: livebox-disk-per-volume

Date: 2026-08-18 · Source: `docs/planning/livebox-disk-per-volume/prd.md`

## Phase 1 — Shared disk core (pure logic) + tests

**Goal:** Add `Shared/LiveBoxDiskCore.swift` with the volume model, percent,
formatter, and display-set filter — all DeckSharedTests-testable, no widget
dependencies.

**Files touched:**
- `native/Shared/LiveBoxDiskCore.swift` (new)
- `native/SharedTests/LiveBoxDiskCoreTests.swift` (new)

**Steps:**
1. `struct RawVolume: Equatable` — the loader seam: `name: String`,
   `mountPath: String`, `totalBytes: UInt64?`, `availableBytes: UInt64?`,
   `isLocal: Bool`, `isReadOnly: Bool`, `identifier: String`.
2. `struct DiskVolume: Equatable` — `name`, `mountPoint`, `totalBytes`,
   `availableBytes`, computed `usedPercent` (0 when total is 0).
3. `enum LiveBoxDiskCore`:
   - `usedPercent(total:available:) -> Double` — `(total-available)/total*100`,
     0 when total ≤ 0.
   - `formatFreeBytes(_:) -> String` — decimal-style (mirror NetBoxFormatters):
     "512 MB free", "195 GB free", "1.2 TB free".
   - `displayName(_ localizedName: String?, mountPath: String) -> String` —
     strip a trailing " - Data" suffix, fall back to the mount path's last
     component when the name is empty.
   - `displayable(_ raw: [RawVolume]) -> [DiskVolume]` — keep only
     `isLocal == true` and both byte counts present; drop mountPath == "/"
     (sealed system volume), the `/System/Volumes/*` siblings **except**
     `/System/Volumes/Data`, and pseudo mounts (`/dev`, `/private/var/vm`,
     `/home`, `/net`); dedupe by `identifier`; sort by `usedPercent` descending;
     cap at `maxVolumes = 5`.
4. Tests (TDD, RED first): percent math (incl. zero-total), formatter units and
   rounding, name stripping ("Macintosh HD - Data" → "Macintosh HD", empty-name
   fallback), filter acceptance/rejection per rule (keep Data, drop `/`, drop
   Preboot/VM/Update, drop non-local, drop nil-capacity), dedupe by identifier,
   sort + cap. Also a no-input → empty test.

**Verification:** `xcodebuild test -project native/Deck.xcodeproj -scheme DeckSharedTests -derivedDataPath native/build CODE_SIGNING_ALLOWED=NO` — new suite passes and "Executed N test" count includes the new tests.

**Dependencies:** none.

## Phase 4 — Widget large face

**Goal:** Render per-volume rows on the large face; keep small/medium and the
aggregate fallback.

**Files touched:**
- `native/DeckWidgets/LiveBoxWidget.swift`

**Steps:**
1. `LiveBoxSampler.volumes()` → `LiveBoxDiskCore.displayable(diskVolumeSamples())`.
2. Pass `volumes: [DiskVolume]` into `LiveBoxFace` (sampled in the same 5s
   `TimelineView` tick as `sample()`).
3. Large face header: show the aggregate DISK row only when
   `settings.showDisk && !(settings.showPerVolumeDisk && !volumes.isEmpty)`
   (CPU/MEM always as today).
4. Large face body, below the chart and above the processes section: when
   `settings.showDisk && settings.showPerVolumeDisk && !volumes.isEmpty`,
   render a vertical `VStack` (spacing 2) of per-volume rows —
   `Circle` (DISK color, 7pt) + name (11pt medium, lineLimit 1, tail truncate)
   + Spacer + `%` (monospaced) + free text (11pt, `.secondary`) —
   `ForEach(volumes, id: \.mountPoint)`.
5. Small/medium faces untouched.

**Verification:** `xcodebuild ... DeckApp ... build`; install; re-add LiveBox;
large face shows the volume list (toggle on) / aggregate DISK row (toggle off or
empty volume set); small/medium show the aggregate row in both modes.
