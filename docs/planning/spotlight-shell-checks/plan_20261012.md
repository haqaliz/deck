# Plan: spotlight-shell-checks

Source: `prd.md` (approved 2026-10-12). Adapted to this repo: xcodegen +
xcodebuild, not SwiftPM. Pure logic → `native/SharedTests/`; the throwaway probe
is compiled by hand and lives under `docs/planning/`.

**Standing rules for every phase**
- Quit a running Deck (`pgrep -lf "MacOS/Deck$"`) before anything that reads or
  writes `settings.json` — the app overwrites it from memory.
- Build only into `native/build.noindex`; run `scripts/lsclean.sh` after every
  release build; install by replacing the bundle in `/Applications`.
- Any new `.swift` file under `native/` needs `xcodegen generate --spec
  native/project.yml`, or it is silently not compiled and the suite still passes.
  Check the executed-test count rises.
- Test command: `xcodebuild test -project native/Deck.xcodeproj -scheme
  DeckSharedTests -derivedDataPath native/build.noindex CODE_SIGNING_ALLOWED=NO`
  — expect `Test Suite 'All tests' passed` and **≥ 1665** executed.
- Commit per phase on `task/spotlight-shell-checks/aliz`.

**Files:** `native/DeckApp/DeckApp.swift`.

**Steps**

"com.deck.app"'` returns the line after a cold `open -a` (prove the log answers
with a **cold** case first — CLAUDE.md: `log show` without `--info --debug` is
silent for this app). Suite still 1665; no other diff in behaviour.
**Dependencies:** none. **Gates Phase 2** (the log is the running-case proof).

## Phase 2 — The probe harness

**Goal:** one committed, self-proving harness that drives every automatable check
and prints raw evidence.

**Files:** `docs/planning/spotlight-shell-checks/probe/main.swift` (new),
`docs/planning/spotlight-shell-checks/probe.md` (invocation + results, optional;
may fold into `verification.md`).

**Steps**
1. **`--selftest` (must pass before any check is trusted).** A non-activating
   `NSPanel` + `NSTextField`; post a key via raw `CGEvent`; assert it reaches the
   field. Print `AXIsProcessTrusted()`. This is the positive control that made
   the shell's first helper trustworthy.
2. **`postHotkey [--shortcut k/…]`.** Post ⌥Space (or a re-recorded shortcut) as
   raw `CGEvent` keyDown/keyUp. **Post, never register** — a second process
   registering Deck's combination gets status 0 (CLAUDE.md).
3. **`--url-cold`.** Assert Deck stopped → `open -a /Applications/Deck.app
   "https://example.com/deck-url-check"` → poll `pgrep` for launch→exit; read the
   `com.deck.app` log line; snapshot Deck's window count via
   `CGWindowListCopyWindowInfo` filtered by PID. PASS = started, forwarded (log),
   exited, zero windows.
4. **`--url-running`.** Require Deck up with **tray-only OFF**; same `open`; PASS
   = log line fired, process persists, window count unchanged.
5. **`--agents`.** Sample `processes.json` and `agent-heartbeat.json` mtimes,
   trigger a quit/relaunch, re-sample; PASS = both **advance** (proves
   `LegacyAgentCleanup` did not boot the agents out).
6. **`--panel-probe`.** Post ⌥Space; observe a new Deck-owned window of the
   panel's size/level via `CGWindowList`; report `isVisible` proxy + frontmost app
   (for C4's proxy half).
7. Compile with `swiftc` (as the shell probe was); no signing needed for posting.

**Verification:** `--selftest` prints "event arrived"; every mode prints
PASS/FAIL with the raw numbers; `--url-running` fails loudly if the log line is
absent (guards the C2 false-pass the critique caught).
**Dependencies:** Phase 1 (installed build with the log line).

## Phase 3 — Run and record the evidence

**Goal:** run C1–C5 + the cross-cutting witness against the installed build and
write the report.

**Files:** `docs/planning/spotlight-shell-checks/verification.md` (new).

**Steps**
1. Run the harness modes in order; capture stdout verbatim.
2. **C1 (Human):** the login-item toggle, the Login Items row, and the veto note

   *install → toggle → veto → relaunch* (replacing the bundle resets the veto).
3. **C2 (auto):** `--url-cold` and `--url-running`; record both.
4. **C3 (Human):** real-mouse click-away; a synthesized click is a bonus, not the

6. **C5 (Human):** real Dock menu → Quit, tray-only OFF then ON; AppleScript
   `quit` re-run as the measurable half.
7. Cross-cutting: log the agent-mtime observation and the no-URL-types check.

**Verification:** `verification.md` has one row per C1–C5 + cross-cutting, each
**measured with a recorded command/result** or **handed back as a numbered human
step** — none unclassified.
**Dependencies:** Phase 2.

## Phase 4 — Fixes (conditional; only what a check reveals)

**Goal:** fix a real failure without scope creep.

**Files:** TBD by the run (a new pure rule → `native/Shared/`; delegate wiring →
`native/DeckApp/DeckApp.swift`).

**Steps**
1. Reproduce the failure with the harness.
2. If it is a pure rule: **TDD** — a failing `DeckSharedTests` case first, then the
   fix in `Shared/`; the delegate keeps applying.
3. If it is pure wiring: change it, rebuild, re-run the failing check.
4. Re-run the full suite.

**Verification:** suite green with count ≥ 1665 (higher if a test was added); the
failing check now passes; no unrelated diff.
**Dependencies:** Phase 3. **Skipped entirely if nothing fails** — which is an
acceptable, stated outcome for this task.
