## Phase 1 — OpenBoxCostCore: pure cost aggregation (TDD, scratch SwiftPM package)

**Goal**: proven row→model mapping, day×model flattening, series consolidation
and legend IDs for the stacked chart.

**Files touched**:
- `Package.swift` — scratch package: library `OpenBoxCostCore` + test target
  `OpenBoxCostCoreTests`.
- `Sources/OpenBoxCostCore/CostDay.swift` — `CostDay: Codable, Equatable
  { let day: String; let model: String; let cost: Double }`; pure
  `mapRows(_ rows: [[String: Any]]) -> [CostDay]` (row.string("day") +
  row.string("model") + row.double("cost") ?? 0; drops rows missing day or
  model; sorts by day, then cost desc).
- `Sources/OpenBoxCostCore/SeriesBuilder.swift` —
  `daily(fromDayModelCosts: [String: [String: Double]]) -> [CostDay]` (flattens
  the remote loader's accumulator, same sort); `buildSeries(from: [CostDay],
  topN: Int = 3) -> [Series]` where `Series: Equatable { model: String;
  costs: [Double] }` — day order preserved from the input, one value per day
  per series, top-N series by total cost (ties stable by first-appearance),
  remainder merged into `"other"`; and `displayID(of raw: String) -> String`
  — JSON-object → `$.id`, else last `/`-segment (matches `ModelParser.parse`
  for the widget's legend).
- `Tests/OpenBoxCostCoreTests/CostDayTests.swift`.

**Steps** (TDD: failing test → green):
1. `CostDay` + `mapRows([])` → `[]`.
2. `mapRows`: mixed rows (valid, nil-day dropped, nil-model dropped, cost
   missing → 0) → sorted day asc, cost desc within a day.
3. `daily(fromDayModelCosts:)`: dict → sorted `[CostDay]`; empty dict → `[]`.
4. `buildSeries`: single model → one series with a value per input day;
   >3 models → top 3 + "other" with merged costs, stable tie order;
   topN 0 → all "other"; empty input → `[]`.
5. `displayID`: JSON object → `id`; `opencode-go/deepseek-v4-flash` →
   `deepseek-v4-flash`; no slash → raw.
6. Live shape parity: hand-built `[[String: Any]]` mirroring
   `rows(db, costDailySQL)` output (day as String, model as String, cost as
   Double) with the Phase-2 fixture (deepseek-v4-flash ~6.1765 total, qwen
   0.0288, r1 0.0136) → expected series [deepseek-v4-flash, qwen, r1].

**Verification**: `swift test` — all OpenBoxCostCoreTests green.

**Dependencies**: none.

## Phase 2 — Snapshot + reader + remote parity (native)

**Goal**: the snapshot carries `costDaily`; the agent produces it from the
local DB; remote serve mode fills the same field (no degrade).

**Files touched**:
- `native/Shared/OpenCodeSnapshot.swift` — `CostDay` struct (ported);
  `OpenCodeSnapshot` gains `var costDaily: [CostDay]`; memberwise `init` gains
  the parameter (three call sites updated: OpenCodeReader.load,
  RemoteOpenCodeLoader's two aggregates); tolerant `init(from:)` adds
  `costDaily = try c.decodeIfPresent([CostDay].self, forKey: .costDaily) ?? []`
  (PR #8 pattern — old `opencode.json` decodes).
- `native/Shared/OpenCodeReader.swift` — `costDailySQL`:
  ```sql
  SELECT date(time_created/1000,'unixepoch') as day, model,
         ROUND(SUM(cost), 4) as cost
  FROM session
  WHERE time_created > (strftime('%s','now','-13 days')*1000)
    AND model IS NOT NULL
  GROUP BY day, model ORDER BY day
  ```
  filled via the ported `mapRows`.
- `native/Shared/RemoteOpenCodeLoader.swift` — both `aggregate(...)`s add a
  `dayModelCosts: [String: [String: Double]]` accumulator alongside
  `dayTotals`: sessions path keys by `modelKey(for:)`, messages path by
  `"\(providerID ?? "local")/\(modelID ?? "unknown")"` (the existing
  `modelTotals` key); both returns pass
  `costDaily: SeriesBuilder.daily(fromDayModelCosts:)` (ported inline).

**Steps**:
1. Port Phase-1 `CostDay` + `mapRows` into `OpenCodeReader` (reusing the
   existing `rows()`/`string()`/`double()` helpers); snapshot struct + tolerant
   init + call-site params.
2. Remote aggregates accumulate + flatten.
3. `xcodebuild ... build` green.
4. Run the built `DeckAgent` binary directly; confirm `opencode.json` gains
   `costDaily` with the expected day×model rows and every other field
   unchanged.

**Verification**: build green; agent snapshot diff shows only `costDaily`
added. Remote path is covered by Phase-1 fixtures of the pure flatten + by
build; a live `opencode serve` check is optional (same code path as models).

**Dependencies**: Phase 1.

## Phase 4 — Widget front face (chart switch + legend)

**Goal**: OpenBox renders the stacked cost chart in the existing chart slot
when the toggle is on.

**Files touched**:
- `native/DeckWidgets/OpenBoxWidget.swift` — `OpenBoxEntry` gains
  `let costDaily: [OpenCodeSnapshot.CostDay]`; three construction sites:
  `placeholder()` (sample costDaily with 2 models), `unavailable` entry
  (`[]`), `makeEntry()` (`snapshot.costDaily`). Chart slot logic becomes:
  ```
  if entry.settings.showChart && !entry.daily.isEmpty {
      if entry.settings.showCostChart && !entry.costDaily.isEmpty {
          costChart          // stacked bars
      } else {
          chart              // existing token lines
      }
  }
  ```
  `costChart`: `Chart` of `BarMark` (x = day index, y = cost,
  `foregroundStyle(by: .value("Model", model))`) built from
  `SeriesBuilder.buildSeries` (ported) — `series.costs[i]` per day index,
  `chartForegroundStyleScale` mapping first series to `costColor`, rest to a
  fixed palette (teal, pink, gray), hidden axes, same heights (medium 62,
  large 56). Legend row (large only, below chart): colored dots + `displayID`
  labels, 9pt, `lineLimit(1)`, one row per series including "other".

**Steps**:
1. Entry + provider changes (three sites).
2. Port `buildSeries` + `displayID`; `costChart` + legend views; wire the
   switch.
3. `xcodebuild` Release; install to `/Applications`; relaunch; `pluginkit`.

**Verification**: re-add OpenBox from the gallery; toggle on → stacked cost
bars (dominant model in COST color, "other" merged when >3 models); toggle off
→ token lines unchanged; medium/large both render, small unchanged; stale
`costDaily` empty → chart slot hides; remote mode renders the same chart from
server data; other widgets unchanged.

**Dependencies**: Phases 2, 3.
