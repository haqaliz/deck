# L2 shell — verification

**Date:** 2026-11-19.
**Target:** Pi 4B, Pi OS Trixie, labwc 0.9.2, GTK 4.18.6.
**Build:** debug `deck-gui` (107MB, unoptimised); release build is a later packaging step.

## Verified

- `deck-gui` starts under labwc, creates the layer-shell widget surface, binds
  `$XDG_RUNTIME_DIR/deck.sock`, registers a `ksni` StatusNotifierItem and shows
  the tray icon in `wf-panel-pi`.
- `deck --toggle-search` connects to the socket and opens the search overlay:
  a focused entry, dark Deck panel, Escape hides it. Screenshot:
  `evidence/l2-search.png`.
- `settings` over the socket opens the custom-header settings window with
  General, Search, Credentials and Widgets tabs. Screenshot:
  `evidence/l2-settings.png`.
- The General tab's autostart toggle wrote
  `~/.config/autostart/deck.desktop` with the running GUI path.
- `deck --install-shortcut` wrote a marked `W-Space` binding into
  `~/.config/labwc/rc.xml`, ran `labwc --reconfigure` with `LABWC_PID`, and
  `wtype -M logo -k space` opened the search panel. The binding calls
  `…/deck --toggle-search` (the missing argument was found and fixed during
  this test).
- The layer-shell widget is a bottom surface; the terminal covered it in the
  screenshots, so the visible proof remains the L0 layer test plus the same
  `surface.rs` backend. The search overlay is the same layer-shell path on the
  `Overlay` layer.
- `cargo fmt`, `cargo clippy -D warnings` and `cargo test --workspace` are green
  on the Pi (22 core + 2 daemon tests).

## Test cleanup

The dev GUI is not left autostarting: the test `~/.config/autostart/deck.desktop`,
the test labwc keybinding, the socket and the test XDG dirs were removed after
the run. The source and compiled `~/deck-linux` remain for L3.

## Not tested

- KDE Plasma, GNOME Wayland, wlroots and generic X11. Their backends are the
  L7 matrix; GNOME keeps the documented dashboard fallback.
- Per-monitor placement and settings persistence beyond autostart.
- Clicking the tray menu items; the Service Item and icon are verified, the
  callbacks are straightforward but not automated.
- A systemd-enabled `deckd` login; the unit file exists but is not enabled in
  this dev run.

## Fixes found during the milestone

- labwc shortcut command needed `--toggle-search`; the installer now writes the
  full command, not just the binary path.
- zbus/zbus_macros/zbus_names/zvariant/uuid are pinned in `Cargo.lock` for Rust
  1.85.1; the latest zbus requires 1.87.
- `time` is pinned to 0.3.36 for the same reason.
