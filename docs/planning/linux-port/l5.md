# L5 infra widgets and search — verification

**Date:** 2026-11-19.
**Target:** Pi 4B (4GB), Pi OS Trixie, labwc 0.9.2, GTK 4.18.6.
**Build:** debug; release packaging is L6.

## Verified

- **LogBox**: Elastic error/warn counts for the small and large windows, 24h
  trend bars, services, templates, recent error lines, the 15-minute slow-block
  cache, `ApiKey` auth, base-URL validation and a Kibana link. The live cluster
  was not available, so the face was verified with a seeded snapshot;
  `ElasticLogParser` is fixture/payload-tested.
  Screenshot: `evidence/l5-widgets.png`.
- **MetricBox**: Prometheus datasource discovery, one `/api/ds/query` for the
  fleet columns, agents, firing alerts, single-host trend, power/monthly-cost
  estimate and a Grafana link. Verified with a seeded snapshot built from the
  macOS Grafana fixtures; live Grafana was not available.
  Screenshot: `evidence/l5-widgets.png`.
- **Charts**: LogBox trend bars, MetricBox host trend and MarketBox 7-day
  sparklines in Cairo. Screenshot: `evidence/l5-market-large.png`.
- **Search providers**: 13 providers — `port`, `time`, `oc`, `run`, `sys`,
  `net`, `git`, `weather`, `task`/`bug`/`pbi`/`epic`/`feature`/`wi`, `pr`,
  `log`, `metric`, `mkt`.
  - Prefix only scopes after whitespace; work-item prefixes carry their type.
  - Sections keep a fixed order, are ranked by score then title/id, and cap at
    5 (10 when scoped).
  - Every provider is snapshot/local: no search-time network call, so the
    background fetch budget is untouched.
  - The panel groups sections, selects the first result, supports Up/Down,
    Enter/click activates, Escape closes, and Copy/Open actions.
  - Debounce is a 180ms generation counter; a fired timer can no longer remove
    its own `SourceId` and abort the GUI (found and fixed during this run).
  - Screenshots: `evidence/l5-search-deck.png` (Builds + System + Git),
    `l5-search-task.png`, `l5-search-time.png`, `l5-search-run.png`,
    `l5-search-port.png`, `l5-search-log.png`, `l5-search-metric.png`,
    `l5-search-market.png`, `l5-search-weather.png`, `l5-search-git.png`,
    `l5-search-net.png`, `l5-search-oc.png`, `l5-search-sys.png`.
- **Settings**: Widgets hub includes Logs and Metrics; Credentials now has
  GitHub, Azure, Elastic and Grafana rows plus the opencode check. LogBox has a
  “Load catalogs” action for environments/services.
  Screenshots: `evidence/l5-settings.png`,
  `l5-settings-widgets.png`, `l5-settings-credentials.png`.
- `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace` are green on the Pi (97 core + 3 daemon tests).

## Not verified / deferred

- No live Elastic or Grafana account on this Pi, so LogBox/MetricBox fetches
  and the Verify buttons were not exercised against real clusters. Parsers and
  faces are fixture/seeded-snapshot verified.
- Search is snapshot-backed. Remote full-text search, per-source floor, shared
  cache and 429 isolation are not implemented; the rate rule is satisfied by
  making no search-time network calls at all.
- Search provider toggles are not exposed in settings; all providers are on.
- LogBox “Full lines” uses the `message`/template field already present in the
  snapshot, not the raw document.
- Kibana/Grafana links point at the configured base URL (Discover/home), not a
  query-specific deep link.
- MetricBox host/service pickers are not dynamic; the host comes from the
  snapshot and the single-host field is typed.
