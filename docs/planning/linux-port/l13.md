# L13 — CalBox picker, ClipBox and BatBox

Three follow-ups after CalBox: choose which calendars are read, a
clipboard-history widget, and a battery widget.

## CalBox calendar picker

- `calbox::calendars()` exposes the CalDAV discovery list to Settings.
- Calendar settings now have a **Load calendars** button. Each discovered
  calendar is shown with its colour and a checkbox.
- An empty selection means every VEVENT calendar; unchecking a calendar stores
  the remaining ids, and checking everything collapses back to “all”.
- `calbox::fetch` filters the REPORT loop by the selected ids.
- Changes apply on the next `deckd` tick.

## ClipBox

- Text clipboard history using `wl-paste` on Wayland and `xsel`/`xclip` on
  X11. `wl-clipboard` is a package dependency.
- The widget polls once per second in a background thread, deduplicates,
  promotes re-copies to the front and keeps the last 50 items.
- History is stored at `~/.local/share/deck/clipboard.json` with mode 0600.
- Rows show a kind dot, one-line preview and relative time; clicking a row
  copies it back with `wl-copy`/`xsel`/`xclip`.
- Settings: enable, size, show list, visible row count, text colour and
  link/file colour.
- `clip` search queries include clipboard history.
- Small/medium/large heights are 150/230/330.

## BatBox

- Reads `/sys/class/power_supply` directly: battery capacity/status and time
  left from `time_to_empty_now`, `energy_now/power_now` or
  `charge_now/current_now`; AC/USB online state.
- Widget shows BATTERY, TIME LEFT and STATE rows, with a low-battery colour and
  an accessories section (empty until a BlueZ source is added).
- Settings: enable, size, show battery, show accessories, low threshold.
- On the Pi the widget correctly reports no battery.

## Known gaps

- ClipBox stores text only; images, files and rich text are skipped.
- Wayland requires `wl-clipboard`; the AppImage cannot bundle it, so the host
  package is required.
- Clipboard history polling is once per second; very fast copy sequences can
  miss an intermediate entry.
- BatBox accessories are not populated yet (BlueZ/UPower device battery
  integration is deferred).
- BatBox has no Pi battery to exercise on real hardware; parser tests cover the
  sysfs shapes.
