# L12 — CalBox (CalDAV)

First post-v1 widget: CalBox, using CalDAV instead of macOS EventKit.

## What shipped

- **CalDAV client** (`deck-core/src/calbox.rs`):
  - `PROPFIND` discovers calendars, their display names, colours and VEVENT
    support.
  - `REPORT` fetches a today/tomorrow horizon; servers are asked to expand
    recurrence rules, with a retry without `expand` for servers that reject it.
  - ICS parsing handles UTC, floating-local and date-only `DTSTART`/`DTEND`,
    line folding, escaped summaries, `URL`, all-day events and cancelled rows.
  - Calendar colours are normalised from `#RRGGBBAA`; missing colours get a
    stable palette entry.
- **Daemon**: `calbox` fetches when enabled, using the CalDAV password under
  credential id `caldav` and the username in settings.
- **Widget**: TODAY and TOMORROW sections, all-day rows first, coloured dots,
  `HH:mm` times, links for event URLs, per-section row caps, overflow count
  and empty states. Small/medium/large heights are 150/240/340.
- **Settings**: size, enable, server URL, username, all-day/today/tomorrow
  toggles, row counts, calendar colours toggle and accent colour.
- **Credentials**: CalDAV password row with a Verify button that reports the
  number of calendars discovered.
- **Search**: `cal` / unscoped queries include calendar events from the current
  snapshot, with a start-time + calendar subtitle.

## Tests

- CalDAV multistatus parsing (calendar discovery, colours, URLs).
- ICS parsing of timed, all-day, escaped and linked events.
- Relative/absolute href resolution.
- Settings defaults and the CalDAV Verify path share the existing credential
  tests.

## Known gaps

- No live CalDAV server was available; only fixtures exercise discovery and
  event parsing.
- One server + username/password pair. Google OAuth, EventKit and iCloud
  app-specific-password flows are not implemented.
- Calendar selection is all-or-nothing: every VEVENT calendar is read. The
  macOS per-calendar picker is not ported yet.
- Recurrence expansion depends on the server; when it refuses `expand`, only
  the master occurrence is shown.
- Floating times are interpreted in the machine's local timezone; `TZID` is
  ignored.


## v0.5.1 patch

Widget dragging is now frame-coalesced: gesture updates store a target
position, and one tick callback applies it at most once per compositor frame.
The drag code also compensates for the window moving under the pointer, which
previously made the card move at half speed and feel sticky. Tooltip windows
were removed from the drag grips.
