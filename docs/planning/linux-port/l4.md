# L4 network widgets — verification

**Date:** 2026-11-19.
**Target:** Pi 4B (4GB), Pi OS Trixie, labwc 0.9.2, GTK 4.18.6.
**Build:** debug; release packaging is L6.

## Verified

- **WeatherBox**: live `wttr.in/?format=j1` fetch for Amsterdam, resolved to
  Buitenveldert; current conditions and three forecast days. Screenshot:
  `evidence/l4-widgets-medium.png`.
- **MarketBox**: live crypto from CoinGecko, gold from gold-api, stocks from
  Yahoo, fiat cross-rates from open.er-api and the Toman anchor from Wallex;
  USD display; day-change colours. Screenshot: `evidence/l4-widgets-medium.png`.
- **GitBox**: local repo scan plus `git log`, today/streak/15-day bars; verified
  with a throwaway repo containing two commits today and one yesterday.
- **ClockBox**: local, Amsterdam and Tokyo rows with correct `+0HRS`, `+1:00`
  and `+9:00` offsets; IANA zones are resolved through `chrono-tz`.
- **OpenBox**: local `opencode.db` reader over `rusqlite` (bundled SQLite);
  today tokens/cost, models, tools and sessions. Verified against a synthetic
  database with the same schema as opencode.
- **ShipBox**: GitHub Actions runs, totals and rows. Live calls need a token;
  the parser is fixture-tested and the face was verified with a fixture
  snapshot: `evidence/l4-widgets-medium.png`.
- **TaskBox**: Azure DevOps WIQL + work-item fetch, lane mapping and face.
  Parser and face verified with fixtures; live calls need a PAT.
- **PRBox**: GitHub search and Azure DevOps PR queries, authored/review
  dedupe and face. Parsers and face verified with fixtures.
- **Sizes**: small/medium/large on every face. `evidence/l4-widgets-small.png` is the
  small wall, `l4-widgets-medium.png` the medium wall and
  `l4-widgets-large.png` the large Market/Tasks/PR faces.
- **Settings**: one Widgets hub with all eleven faces on the left, and a
  Credentials tab with GitHub, Azure and opencode rows. Screenshots:
  `evidence/l4-settings.png`, `l4-settings-widgets.png`,
  `l4-settings-credentials.png`.
- **Failure policy**: each source writes its own `fetch-*.json`; a failure
  leaves the last good snapshot in place and the face shows a status line.
  `shipbox`, `taskbox` and `prbox` correctly reported `notConfigured` without
  a token while the other five widgets kept working.
- `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace` are green on the Pi (74 core + 3 daemon tests).

## Not verified / deferred

- No GitHub token or Azure PAT is available on this Pi, so live Ship/Task/PR
  fetches were not exercised. Parsers and faces use the macOS fixtures.
- Elastic and Grafana credential rows are deferred to L5 with their widgets.
- OpenBox remote-server mode is not implemented; local SQLite only.
- ShipBox automatic repo discovery is not implemented; the Linux face uses the
  explicit `owner/repo` list (multi-repo merge is implemented).
- PR per-provider toggles and review-state glyphs are deferred; both provider
  tokens drive one queue.
- Market has no interactive picker; symbols are a settings list.
- Windows and Azure multi-account binding are deferred; one account per
  provider in this slice.

## Observations

- `curl` is the HTTP transport: the request is written as a curl config on
  stdin, so a token never appears in the process list, and redirects are not
  followed.
- The Pi has no `sqlite3` CLI, so OpenBox uses bundled `rusqlite`.
- A single `deckd --once` with weather, market, git and opencode enabled took
  about two seconds on the Pi.

## Test cleanup

The test settings, snapshots, opencode database, demo git repo, socket and
screenshots were removed from the Pi. The GUI is not autostarting.
`~/deck-linux` remains for L5.
