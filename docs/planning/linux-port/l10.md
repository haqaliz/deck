# L10 — Deferred search and widget follow-ups

Second post-v1 pass: the work that could be done without the clean-desktop
matrix, Pi 5 or live accounts. It also finishes the macOS-parity loose ends
that do not depend on compositor features.

## Search

- **Provider toggles.** Search settings now list all 13 providers with a
  switch. Disabled providers are skipped by the local engine and by the
  remote runners.
- **Remote work-item search.** An unscoped query (or `task …`) asks Azure
  DevOps for matching titles through WIQL, maps the rows through the same
  scoring as local results and merges them into the Work items section.
- **Remote pull-request search.** `pr …` refreshes PRBox's authored and
  review-requested queues and filters them by the typed text.
- **Cache and 429 isolation.** A query answer is cached for 60 seconds
  (48 entries). A 429 pauses only that source for 60 seconds; the other
  source and every local section keep working. Stale remote answers are
  discarded by the same generation counter as local renders.
- **Query-specific Kibana links.** Log service, template and recent-line
  results now open Discover with the matching KQL query and a `now-15m`
  range instead of copying text.

## Widgets

- **LiveBox per-core chart.** A `Per-core CPU lines` toggle draws every core
  as a dim line under the CPU/MEM/DISK series. Defaults off, matching macOS.
- **LiveBox colors.** CPU, MEM, DISK and GPU colors are stored as `#rrggbb`
  and applied to dots, values, volume rows and chart lines.
- **ShipBox auto-discovery.** An empty repo list discovers the five most
  recently pushed repositories where the token has push permission.
- **PRBox provider toggles.** GitHub and Azure can be disabled independently;
  disabled providers are not fetched.
- **PRBox review state.** Azure reviewer votes become approved/changes-
  requested glyphs. When `Review state` is on, GitHub rows make one bounded
  per-PR review request; off skips those calls. A failed lookup simply leaves
  no glyph.
- **Market live picker.** Search CoinGecko from Market settings, then click a
  row to append its symbol to the widget's list.
- **OpenBox remote mode.** A server URL switches OpenBox from the local SQLite
  file to `opencode serve` session-level usage (Basic auth with the opencode
  token). Servers that only expose per-message usage are not aggregated yet
  and keep the last snapshot.

## Shortcuts and packaging

- **KDE shortcut installer.** Writes a hidden `Deck Search` desktop entry and
  the `_launch` entry in `kglobalshortcutsrc` via `kwriteconfig6/5`, then
  rebuilds the KDE service cache. Plasma picks it up on the next login.
- **GNOME/KDE removal.** `deck --remove-shortcut` now removes the GNOME
  keybinding or the KDE launcher and config entry.
- **Tag-triggered releases.** Both Linux workflows already built on
  `linux-v*` tags; they now have a release job that ensures the GitHub release
  exists and uploads the `.deb`/AppImage and checksums.
- **CI secret scan.** The Linux workflow fails on common committed-token and
  private-key patterns.

## Known gaps

- **Multi-account credentials** still need a schema for account metadata and
  per-widget account selection; the single-token store is unchanged.
- Settings pages are still one grouped card per pane rather than one card per
  section.
- GTK layer surfaces still cannot provide macOS vibrancy blur.
- OpenBox remote mode does not aggregate per-message usage from older
  servers; the local database remains the fallback.
- The Market picker searches coins only; stock lookup still uses typed
  symbols.
- Remote search is Azure work items and PRs; log/metric full-text search still
  reads snapshots.
