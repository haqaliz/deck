# L16 — v1.0.0

Feature freeze for the Linux app.

## Included

- All 16 widgets: the original 13 plus CalBox, ClipBox and BatBox.
- Native-looking widget faces, search and settings.
- CalDAV, clipboard history, battery/accessory state.
- Remote work-item, PR and log search with cache and 429 isolation.
- Named multi-provider credentials with per-account Verify.
- Flatpak, `.deb` and AppImage packaging from one tag.
- X11 search-panel centring; Openbox desktop hints.
- Container checks for Sway layer-shell, X11/Openbox and Secret Service.

## Deliberately outside v1.0.0

- Native KDE Plasma widgets and a GNOME Shell extension. These are new
  implementations that need those desktops to build and test; they are not
  part of the GTK app.
- Auto-update. It needs a signed update feed and separate `.deb`, AppImage and
  Flatpak behaviours.
- ARM32 and Pi Zero. No hardware or maintained cross-sysroot.
- Pi 5, a fresh Pi OS image, KDE/GNOME Wayland, KWallet, multi-monitor and the
  physical clean-desktop matrix.
- Live CalDAV, GitHub/Azure/Elastic/Grafana and opencode accounts; these are
  fixture/mock tested.
- GitHub Enterprise server URLs (stored but not used by the client).
- BatBox accessories beyond sysfs HID/UPower-style devices.

## Verification

- 127 core + 3 daemon + 3 GUI + 3 platform tests, fmt and clippy green.
- Flatpak, `.deb` and AppImage built by CI from the `linux-v1.0.0` tag.
