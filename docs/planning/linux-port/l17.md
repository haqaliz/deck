# L17 — Update check and remote dashboards

Two code-only polish items after v1.0.0.

## Update check

- General → Surface has a **Check for updates** button.
- It reads the latest GitHub release and compares it numerically with the
  running version; the result links to the release.
- This is a check, not a self-updater: installation stays with the package
  manager, AppImage or Flatpak.

## Remote Metrics search

- A `metric …` query now asks Grafana `/api/search` for matching dashboards.
- Results merge into the Metrics section and open the dashboard URL.
- The source uses the selected Grafana account token/base URL, the same
  per-source 60-second cache and 429 backoff as work items, PRs and logs.
- Metric snapshot search (hosts, agents, alerts) still answers instantly.

## Verification

- Core tests cover release parsing/version ordering and Grafana search
  parsing.
- 130 core + 3 daemon + 3 GUI + 3 platform tests, fmt and clippy green.

## Known gaps

- No live Grafana account or GitHub release feed was used; parsing is
  fixture-tested.
- GitHub Enterprise URLs remain unused.
- X11 search placement remains window-manager dependent.
- OpenBox older servers still lack per-message aggregation.
