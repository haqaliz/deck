# L9 — macOS visual parity

Deck for Linux keeps the Rust + GTK4 implementation but now follows the macOS
app's visual language and organisation. This is a visual pass, not a behaviour
port: the snapshot contract, providers, thresholds and settings fields are
unchanged.

## What changed

### Design system

- `linux/assets/deck.css` now defines the shared macOS palette: near-black
  gradient cards, `#f5f5f7` primary text, `#9a9aa1` secondary text, the SF
  accent set (`#30d158`, `#40c8e0`, `#ff9f0a`, `#0a84ff`, `#ff375f`,
  `#ff453a`, `#bf5af2`, `#ffd60a`), muted uppercase section labels and rounded
  rows.
- Widget cards use the same 22 px radius and vertical gradient at every size.
- The old widget title rows are gone. A small drag grip in the top-right
  corner keeps widgets movable without adding a macOS-less title.

### Widget faces

- **LiveBox** matches the macOS large face: metric row, transparent chart,
  volume rows, a divider, and `TOP PROCESSES` with a CPU/MEM segmented toggle.
  Process rows show name, right-aligned CPU percent and right-aligned memory
  percent, with the active column tinted. The old `CORES` text row was removed.
- **NetBox** stacks DOWN/UP/ACTIVE on small and right-aligns per-interface
  `↑`/`↓` rates with optional packets and errors.
- **DevBox** right-aligns port addresses in the port accent colour.
- **GitBox** shows the TODAY/STREAK count rows, the 15-day bar chart with the
  current day highlighted, and right-aligned per-repo counts.
- **TaskBox** shows the total/sprint header, a coloured lane legend, and
  coloured task rows instead of the old text legend and metadata lines.
- **PRBox**, **ShipBox**, **OpenBox**, **LogBox** and **MetricBox** use the
  same dot/count/right-aligned-value rows.
- **ClockBox** uses cyan 24 px times in three-column rows (34 px on small).
- **WeatherBox** shows the large glyph/temperature, right-aligned location,
  feels-like/humidity/wind line and a three-column forecast.
- **MarketBox** uses the blue currency header, muted symbols, grouped prices
  and right-aligned day change. Prices only carry `$` for USD.

### Search

- The panel is a dark translucent 20 px card with an oversized borderless
  field, inset divider, uppercase section headers and the macOS blue-grey
  selected row.
- Focus no longer draws the GTK entry outline.

### Settings

- The notebook tabs were replaced by a 190 px sidebar: `General`, `Search`,
  `Credentials`, then a `WIDGETS` section listing all 13 widgets with icons.
- Detail pages are single macOS-style grouped cards with section labels
  (`DISPLAY`, `METRICS`, `CHART`, `PROCESSES`, `THRESHOLDS`, …) and switches
  instead of checkboxes.
- General is grouped into `BACKGROUND REFRESH` and `SURFACE`.

### Defaults

- LiveBox now shows 10 processes and TaskBox 12 tasks, matching the density of
  the macOS large faces. Existing settings files are unchanged.

## Known gaps

- GTK layer surfaces do not provide the macOS vibrancy blur. The search card
  uses a translucent fill so it still tints with the wallpaper.
- Settings pages are one grouped card per pane rather than one card per
  section; section labels keep the organisation readable.
- LiveBox has no per-core CPU chart or colour pickers yet. The Linux settings
  model has no colour fields, so the SF palette is fixed.
- The macOS widget gallery previews are not applicable; the requested
  small/medium/large faces are what the Linux windows render.
