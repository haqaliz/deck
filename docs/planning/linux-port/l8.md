# L8 hardening and v0.1.0 release — verification

**Date:** 2026-11-20.
**Target:** Pi 4B / Trixie / labwc; x86_64 AppImage built in Debian Trixie CI.

## Hardening

- **Crash handling**: the GUI and daemon install panic hooks that write
  `last-error.log` / `deckd-last-error.log` under `$XDG_CACHE_HOME/deck`.
  Settings → General shows the first line of the GUI's last crash. The helper
  is unit-tested.
- **Offline/timeout/429**: every fetch already keeps the last good snapshot.
  HTTP 429 now maps to the `rateLimited` outcome, with the face copy “Rate
  limited — showing the last data”. The contract schema includes the value.
- **Config migration**: a settings file with no `schema_version` now reads as
  version 1 instead of 0; corrupt files are still moved aside and replaced by
  defaults. Both paths are tested.
- **Security**: tokens are passed to `curl` on stdin (never argv), header
  values cannot inject config lines, snapshots/settings/status never carry a
  token, and every remote URL used by an action must be `http(s)` with a host.
  No fetch writes to a remote service.
- **Performance**: release build, default cadence. A background 30-minute idle
  sample is recorded in `docs/planning/linux-port/l8-perf.txt` at release time;
  the shorter release sample was 0.53% CPU / 119 MB RSS over 60 s.
- `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace` are green (102 core + 3 daemon tests).

## Definition of done status

1. Pi OS Trixie labwc on a Pi 4B: `.deb` install, 13 widgets, settings,
   search, tray/shortcut, credentials (0600 fallback), uninstall — met.
2. Desktop AppImage built and bundled; clean-desktop launch remains a
   documented release smoke item. KDE/GNOME/wlroots/X11 are not claimed as
   tested.
3. 13 widgets at small/medium/large with the same faces/thresholds where the
   data model matches — met on the Pi.
4. Search covers every ported provider with snapshot-backed results and
   degradation; remote search/cache/429-storm isolation is deferred and
   documented.
5. No token in any snapshot, log or settings file — enforced by construction
   and the credential paths.
6. `cargo test`, `cargo clippy`, x86_64 and aarch64 builds green.
7. Install docs and platform limitations published.

The v1 definition is met for the Pi-first slice, with the known-limitations
