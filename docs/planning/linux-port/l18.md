# L18 — Live visibility, credential targets and macOS row parity

Patch release after v1.1.0.

## Widget visibility

- Every widget window is built once at startup and kept hidden or shown from a
  title registry.
- Flipping a widget's **Show** switch saves the setting and calls
  `refresh_widget_visibility()` immediately; no restart is needed.
- Toggle-off hides the window without stopping its refresh timer.

## Credentials

- The Mac Deck keychain was read and its GitHub, Azure DevOps, Elastic and
  Grafana account tokens were written to the Pi's 0600 file store.
- The Pi has no `secret-tool`, so the file fallback is the active store.
- Azure PR queries now use `connectionData?api-version=7.1-preview`; `7.0` is
  preview-only and returned 400, which made PRBox report `authOrTarget`.
- opencode tokens are stored for both Mac accounts, but both accounts use the
  local database on macOS and the Pi has no opencode database or server URL, so
  they cannot be verified remotely yet.
- CalDAV is not configured in the Mac Deck, so no CalDAV password was copied.

## macOS layout parity

- TaskBox, PRBox, ShipBox and CalBox long links now use the shared 40-character
  truncation, so a long work-item title can no longer widen a 320px widget.
- MetricBox fleet rows use the same tiny progress bars and pressure colours as
  the macOS MiniBar.
- LogBox and MetricBox trend charts use the macOS accent-bar style instead of
  the old blue bars.

## Verification

- 130 core + 3 daemon + 3 GUI + 3 platform tests, fmt and clippy green.
- On the Pi: Tasks, Pull requests, Logs and Metrics fetched successfully with
  the copied credentials; TaskBox keeps its 320px width and LogBox/MetricBox
  match the Mac bar styling.

## Still open

- Native KDE/GNOME widgets, auto-update, ARM32 and live desktop/account matrix.
- opencode needs a server URL and a reachable `opencode serve` before its token
  can be verified.
