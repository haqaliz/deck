# L3 system widgets — verification

**Date:** 2026-11-19.
**Target:** Pi 4B (4GB), Pi OS Trixie, labwc 0.9.2, GTK 4.18.6.
**Build:** debug `deck-gui`; release packaging is L6.

## Verified

- **LiveBox**: CPU from `/proc/stat` (aggregate and per-core), memory from
  `/proc/meminfo`, disk from `statvfs`, top processes from `/proc`, GPU from AMD
  sysfs or `nvidia-smi` (hidden when neither answers), chart, processes and
  mounted volumes in the large face.
- **NetBox**: `/proc/net/dev` rates per interface, packet and error counters,
  pinned interface or auto-sorted list, interface count, large-face chart and
  MB/s warn/alarm row colours.
- **DevBox**: listening TCP/TCP6 ports from `/proc/net/tcp*`, Docker containers
  from `docker ps`, counts and lists; missing Docker shows `none`.
- **Sizes**: small, medium and large for all three faces, chosen in each
  settings tab. Small shows summary rows, medium adds lists, large adds the
  chart, processes and volumes. Screenshots: `evidence/l3-small.png`,
  `evidence/l3-medium.png`, `evidence/l3-large.png`, defaults in
  `evidence/l3-widgets.png`.
- **Settings**: size, refresh, counts, chart toggles, per-metric thresholds and
  NetBox warn/alarm. Screenshots: `evidence/l3-settings-livebox.png`,
  `evidence/l3-settings-netbox.png`.
- **Thresholds**: one shared `tier` table; CPU turned amber and memory red with
  deliberately low thresholds. Screenshot: `evidence/l3-thresholds.png`.
- **Data spot-check**: memory 12-13% and disk 34% matched `free` and `df /`;
  idle CPU 0-2% matched `top` on the same run.
- `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace` are green on the Pi (38 core + 2 daemon tests).

## Pi 4B measurement

60 seconds, default cadence (LiveBox 15s, NetBox 5s, DevBox 10s), debug build:

- CPU: **0.82%** of one core (process ticks over 60s).
- RSS: **111 MB** (109 MiB), stable after the first frame.
- L0's bare layer-shell floor was ~95 MB, so the three faces add ~15 MB.

No sustained load; the next measurement pass is the L8 performance run and the
release build.

## Not tested / deferred

- KDE, GNOME, wlroots and X11: no machine; the L7 matrix. The faces are plain
  GTK4 and use the same surface backend.
- Intel GPU fdinfo: not implemented; AMD sysfs and `nvidia-smi` are coded but
  no AMD/NVIDIA machine was available. No backend means the row is hidden, never
  0%.
- Docker stats: the face uses `docker ps` status only; the Engine API and
  `docker stats` are not needed for v1's counts/status.
- Process names use `/proc/<pid>/cmdline` basename when present and fall back to
  the 15-byte `comm`.
- Volumes are the real local filesystems from `/proc/mounts`; the large face
  shows the first three.

## Test cleanup

The test settings, socket, screenshots and log were removed from the Pi. The
GUI is not autostarting. `~/deck-linux` remains for the next milestone.

## Fixes found during the milestone

- Adding `libc` made the rsynced `Cargo.lock` stale; the Pi rebuilt without
  `--locked` once and the lock was copied back.
- `libc::statvfs` fields are already `u64` on Linux; the redundant casts failed
  clippy.
- Kernel process names are truncated at 15 bytes, so the sampler now prefers
  the `argv[0]` basename for the rows it returns.
