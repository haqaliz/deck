# L19 — Widget flow reflow

Follow-up to L18's live visibility.

## Problem

Every widget was built at startup and passed through the placement loop even
when disabled. Hidden widgets therefore reserved column slots, so enabling a
subset could leave gaps or push visible widgets into an overlapping column.

## Change

- The window registry stores each title, height and window.
- `refresh_widget_visibility()` runs the flow over the enabled widgets only;
  disabled windows are hidden without advancing the cursor.
- Toggling a widget now reflows every visible widget, so gaps close and columns
  stay packed.

## Verification

- Live on the Pi: turning LiveBox off removed it and packed NetBox, Tasks,
  LogBox, DevBox, PRBox and MetricBox into the freed slot; turning it on again
  reflowed them back. Settings saved both values.
- 130 core + 3 daemon + 3 GUI + 3 platform tests, fmt and clippy green.
