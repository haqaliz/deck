## Phase 1 — Shared helper (TDD: RED → GREEN)

**Goal**: a testable tier policy for network rates that turns a raw
bytes/sec value into a `ThresholdTier`, with the `≤0 = no reading` guard and
decimal MB/s thresholds.

**Files touched**:

- `native/Shared/NetBoxCore.swift`
- `native/SharedTests/NetBoxThresholdTests.swift` (new)

**Steps**:

1. **RED**: write `NetBoxThresholdTests` first:
   - `rate 0` and negative → `.normal` for any thresholds (incl. warn/alarm = 0).
   - `rate 1 B/s` with warn=0 → `.normal` (threshold floor protects here too:
     tier is computed from the *floored* thresholds).
   - boundary: exactly warn → `.warn`; exactly alarm → `.alarm`; between →
     `.warn`; below warn → `.normal` (mirrors `ThresholdTierTests`).
   - MB conversion: `warn = 1 MB/s` → `1_000_000 B/s` boundary works.
   - `warn > alarm` → alarm wins (reuses `ThresholdTier` semantics).
   - stale path proxy: `0` totals → `.normal` (no spurious tint).
2. **GREEN**: add to `NetBoxCore.swift`:

   ```swift
   /// Warn/alarm tier for a network rate. Thresholds are in decimal MB/s
   /// (×1,000,000, matching NetBoxFormatters). A non-positive rate is "no
   /// reading" (idle, stale, counter reset) and is never tinted — even when
   /// the configured thresholds are 0.
   enum NetBoxThresholdTier {
       static func tier(rate: Double, warnMBps: Int, alarmMBps: Int) -> ThresholdTier {
           guard rate > 0 else { return .normal }
           let warn = max(1, warnMBps) * 1_000_000
           let alarm = max(1, alarmMBps) * 1_000_000
           return ThresholdTier.tier(value: rate, warn: Double(warn), alarm: Double(alarm))
       }
   }
   ```

   (Internally floors thresholds ≥1 — belt-and-braces with the decode floor in
   Phase 2, and makes the helper safe for any caller.)
3. **REFACTOR**: keep it minimal; no changes to `ThresholdTier` itself.

**Verification**: `xcodebuild -scheme DeckSharedTests test` — new suite green,
existing suites (incl. `ThresholdTierTests`, `NetBoxCoreTests`) untouched green.

**Dependencies**: none.
