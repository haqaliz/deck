# ShipBox — Implementation Plan

Date: 2026-08-14 · Input: `docs/planning/shipbox/prd.md`

## Phase 1 — ShipBoxCore scratch package (TDD)

**Goal**: pure logic — GitHub runs JSON parsing, status mapping, duration
formatting, totals — proven by tests before any app wiring.

**Files touched**: `ShipBoxCore/` (scratch SwiftPM package at worktree root,
removed in Phase 6; ClipBoxCore/OpenBoxCostCore precedent).

**Steps**:
1. `ShipBoxCore/Package.swift` (library + test target, swift-tools 5.10,
   copied from ClipBoxCore) + `Sources/ShipBoxCore/ShipModels.swift`:
   `ShipStatus` enum (`queued/running/success/failure/neutral`), `ShipRun`
   (name, runNumber, branch, status, createdAt, updatedAt, htmlURL),
   `ShipBoxSnapshot`-shaped container (writtenAt, repo, runs).
2. `Sources/ShipBoxCore/StatusMapping.swift`: `(status, conclusion) →
   ShipStatus` — queued/waiting/requested/pending → queued; in_progress →
   running; completed+success → success; completed+failure/timed_out/
   action_required/stale → failure; completed+other (cancelled/skipped/
   neutral) → neutral; anything unknown → neutral.
3. `Sources/ShipBoxCore/RunParser.swift`: parse the GitHub
   `/actions/runs` JSON (`workflow_runs[]` → `[ShipRun]`, newest-first kept
   as-is; all field types are JSON strings, ISO8601 dates) + `total_count`
   extraction.
4. `Sources/ShipBoxCore/RunFormatting.swift`: completed-run duration
   (`updatedAt − createdAt` → `"3m12s"`, `"0m45s"`, ≥1h → `"1h04m"`),
   row detail text (`branch + duration` / `"QUEUED"` / `"RUNNING"`),
   totals line (`2 fail · 3 pass · 1 run` — counts by ShipStatus, neutral
   skipped when zero).
5. Tests (`Tests/ShipBoxCoreTests/`): status mapping table (every
   status/conclusion pair incl. unknowns), parser against a fixture of the
   real API payload shape (dates, null conclusion, mixed statuses, empty
   runs), duration formatting edge cases, totals (RED → GREEN → REFACTOR).

**Verification**: `swift test` in `ShipBoxCore/` — all green.

**Dependencies**: none.

## Phase 2 — Shared data layer

**Goal**: snapshot model + store + host loader + settings struct, compilable
in all three targets.

**Files touched**: `native/Shared/ShipBoxSnapshot.swift` (new),
`native/Shared/DeckSettings.swift`.

**Steps**:
1. `ShipBoxSnapshot` (Codable: `writtenAt`, `repo`, `runs: [ShipRun]`) +
   `ShipBoxSnapshotStore` (file `shipbox.json` in
   `DeckSettings.containerDirectory`, load/save copied from
   `HomeBoxSnapshotStore`) — port `ShipStatus/ShipRun` + mapping + parser +
   formatting from ShipBoxCore (drop the package).
2. `HostGitHubLoader.fetch(repo:token:) async throws -> ShipBoxSnapshot` —
   `GET https://api.github.com/repos/{repo}/actions/runs?per_page=10` with
   `Authorization: Bearer <token>`, `Accept: application/vnd.github+json`,
   `X-GitHub-Api-Version: 2022-11-28`; transport/status checks copied from
   `HostWeatherLoader` (`HomeBoxSnapshot.swift:67-119`); 10s timeout;
   errors: invalidRepo, serverError(Int), transport(String), invalidPayload.
3. `ShipBoxSettings` in `DeckSettings.swift` with tolerant decode:
   `repo = ""`, `token = ""`, `showList = true`, `runCount = 4`,
   `queuedColor = RGBA(.orange)`, `runningColor = RGBA(.yellow)`,
   `successColor = RGBA(.green)`, `failureColor = RGBA(.red)`.
4. `DeckSettings`: add `var shipbox = ShipBoxSettings()`.

**Verification**: `xcodegen generate` + `xcodebuild` Release build green.

**Dependencies**: Phase 1 (ported logic).

## Phase 3 — Agent + app data wiring (with empirical probe)

**Goal**: snapshot flows end-to-end; the live GitHub API contract is probed
for real.

**Files touched**: `native/DeckAgent/main.swift`, `native/DeckApp/DeckApp.swift`.

**Steps**:
1. `DeckAgent/main.swift`: after homebox — skip when `repo` empty or `token`
   empty (no fetch, mirror OpenBox remote guard `DeckAgent/main.swift:15-22`);
   else `if let ship = try? await HostGitHubLoader.fetch(...) { save }`
   (always-written semantics like HomeBox so writtenAt stays honest).
2. **Probe**: run the built `DeckAgent` binary directly from the terminal with
   a token + repo set in `settings.json` (copy from a real Deck install), then
   inspect `shipbox.json` — must contain parsed runs for the repo (also run
   once with a bad token → snapshot stays absent, no crash). If the live
   payload shape differs from the Phase 1 fixture, fix the parser + fixture
   and re-run tests.
3. `DeckApp.swift`: `refreshShipBox()` (host-side, mirrors `refreshHomeBox`),
   wired into `onAppear` + 60s timer; sidebar `DeckWidget.shipbox` case
   (title "ShipBox", systemImage "shippingbox") — tab view placeholder.

**Verification**: probe passes; `xcodebuild` Release green.

**Dependencies**: Phase 2.

## Phase 4 — Widget front face

**Goal**: the card renders runs from the snapshot.

**Files touched**: `native/DeckWidgets/ShipBoxWidget.swift` (new, copy of
`HomeBoxWidget.swift`), `native/DeckWidgets/DeckWidgets.swift`.

**Steps**:
1. `ShipBoxEntry` + `ShipBoxProvider` (placeholder/getSnapshot/getTimeline,
   60s policy; staleness windows copied from HomeBox: fresh <5 min, stale
   hint 5–30 min, unavailable >30 min — `HomeBoxWidget.swift:80-82`).
2. `ShipBoxWidget` (kind `ShipBoxWidget`, small/medium/large,
   description "GitHub Actions run status for a repo") + register in
   `DeckWidgets.swift` bundle.
3. Views: header (repo name truncated + totals line; stale `· HH:mm` hint),
   colored-dot run rows (dot = ShipStatus color, `name #runNumber`, trailing
   branch + duration / RUNNING / QUEUED), small = 2 rows, medium = up to
   `runCount`, large = up to `runCount` + totals row; unavailable view
   ("ShipBox" / "No build data" / "Paste a repo + token in Deck settings.");
   "No runs yet" state for a valid snapshot with zero runs;
   `containerBackground` root (widget shell invariant).
4. `ShipBoxSnapshotStore.load()` + `DeckSettings.load().shipbox` in provider.

**Verification**: `xcodegen generate` + build + install to `/Applications/`,
re-add from the gallery; three sizes show live run status.

**Dependencies**: Phase 3.
