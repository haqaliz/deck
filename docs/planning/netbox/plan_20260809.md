## Phase 0 — Feasibility spike: getifaddrs byte counters

1. **Goal** — Prove `getifaddrs` AF_LINK `ifa_data` exposes `ifi_ibytes`/`ifi_obytes` on this macOS before committing the loader to it.
2. **Files touched** — `/tmp` scratch script (not committed).
3. **Steps**:
   1. Write a tiny swift script: walk `getifaddrs`, for `AF_LINK` interfaces cast `ifa_data` to `if_data *`, print name + `ifi_ibytes`/`ifi_obytes` twice 1s apart (deltas > 0 on an active interface).
4. **Verification** — nonzero increasing counters on `en0` (or any physical NIC); if `ifa_data` is nil/zero, adopt the fallback: `netstat -ib` subprocess (parser moves into NetBoxCore, still TDD'd).
5. **Dependencies** — Phase 2 (NetBoxCore) waits on the loader decision.

## Phase 2 — NetBoxCore: pure models, rates, filter, formatters (TDD)

1. **Goal** — Unit-tested pure logic: sample model, delta math, reset/wrap handling, interface filter, rate formatter, most-active pick.
2. **Files touched** — `Sources/NetBoxCore/Models.swift` (new), `Sources/NetBoxCore/NetworkMath.swift` (new), `Sources/NetBoxCore/Formatters.swift` (new), `Sources/NetBoxCore/InterfaceFilter.swift` (new); `Tests/NetBoxCoreTests/*.swift` (new); `Package.swift` (target `NetBoxCore`, `testTarget` `NetBoxCoreTests`, product lib).
3. **Steps**:
   1. Models: `InterfaceSample(name:rxBytes:txBytes:)`, `RateSample(up:down:)` — plain structs, no timers.
   2. `NetworkMath.rates(previous:current:interval:)` — byte deltas / interval; any negative delta ⇒ rate 0 + signal to reseed baseline (return `didReset`).
   3. `InterfaceFilter` — exclude table (`lo0`, `utun*`, `awdl*`, `llw0`, `anpi*`, `ap*`, `bridge*`, `vboxnet*`, `vmnet*`); keep physical `en*`.
   4. `mostActive(interfaces:)` — pick by max(recent up, down).
   5. `NetBoxFormatters.formatRate(_ Bps)` — `B/s`, `KB/s`, `MB/s`, `GB/s` (1 decimal).
   6. Tests first (RED) per function, then implementation (GREEN): delta math, reset/wrap, exclusion table rows, formatter thresholds, most-active tie-break.
4. **Verification** — `swift test` green (all of the above).
5. **Dependencies** — Phase 0 (loader decision fixes only which side of the bridge is thin; Core is identical either way).

## Phase 3 — Loader + MetricsStore wiring

1. **Goal** — The shell MetricsStore polls the new loader; published up/down rates, chart history, and interface list update every second.
2. **Files touched** — `Sources/NetBox/Metrics/NetworkMetrics.swift` (new; thin `getifaddrs` bridge if spike passed, else `netstat -ib` parser using NetBoxCore), `Sources/NetBox/MetricsStore.swift` (rewrite from LiveBox copy).
3. **Steps**:
   1. Loader: sample all interfaces → filtered `[InterfaceSample]`; keep previous sample; compute rates via `NetworkMath.rates` (reseed on reset).
   2. Store: 1s timer (LiveBox pattern); published `headerInterface` (most active), `interfaces: [(InterfaceSample, up, down)]`, `history: [RateSample]` (cap 90, reseeds when header interface changes per PRD §2).
3. **Verification** — `swift test` still green; `swift build`; brief `swift run NetBox` prints plausible rates in Console/observes store values changing (temporary debug print, removed next phase).
4. **Dependencies** — Phase 2.
