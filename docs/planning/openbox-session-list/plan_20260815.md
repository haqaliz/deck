## Phase 1 — Pure logic: session row mapper + relative-time formatter (TDD)

**Goal:** the testable core — mapping raw session rows to `SessionRow`s and
formatting relative time — exists with tests.

**Files touched:** `native/Shared/OpenBoxCore.swift`,
`native/SharedTests/OpenBoxSessionCoreTests.swift` (new).

**Steps:**
1. RED — write `OpenBoxSessionCoreTests`:
   - `OpenBoxSessionList.relativeTime(from:to:)`: 30s → "just now", 90s →
     "1m ago", 2h → "2h ago", 24h+ → "1d ago", 3d → "3d ago"; future date
     clamps to "just now".
   - `OpenBoxSessionList.map(_:now:limit:)`: input rows `[[String: Any]]`
     with `title/tokens_input/tokens_output/time_created`; asserts ordering
     by total tokens desc, top-N cap, nil-title and empty-title rows dropped,
     `time_created` (epoch ms) → `Date`.
2. GREEN — implement in `OpenBoxCore.swift`:
   - `enum OpenBoxSessionList` with `struct Row` (`title`, `input`, `output`,
     `timeCreated: Date`) and the two pure functions. The mapper owns
     ordering + filtering + capping so SQL stays simple (window only).
3. REFACTOR — keep the mapper row-shaped (`[[String: Any]]` in,
   `[Row]` out) matching `OpenCodeReader.mapToolRows`'s style.

**Verification:** DeckSharedTests green.
**Dependencies:** none.

## Phase 2 — Snapshot field + reader SQL

**Goal:** the snapshot carries `sessionList`; the reader fills it from the DB.

**Files touched:** `native/Shared/OpenCodeSnapshot.swift`,
`native/Shared/OpenCodeReader.swift`, `native/SharedTests/OpenCodeSQLTests.swift`.

**Steps:**
1. `OpenCodeSnapshot`: add `struct SessionRow: Codable, Equatable`
   (`title`, `input`, `output`, `timeCreated`) and `var sessionList:
   [SessionRow]` — memberwise init updated, tolerant decode
   (`decodeIfPresent ?? []`, PR #8 pattern).
2. RED — in `OpenCodeSQLTests`: extend `CREATE TABLE session` with a `title`
   TEXT column and the INSERT helper with a title param. New test seeds 4
   sessions — 2 inside the 14-day window (different token totals), 1 outside,
   1 inside with NULL title — and asserts `snapshot.sessionList`: window-only,
   ordered by total tokens desc, nil title dropped, `timeCreated` decoded.
   (Check existing assertions still pass — the fixture now yields non-empty
   `sessionList`, which only affects Equatable comparisons, not other fields.)
3. GREEN — `OpenCodeReader`: `sessionsSQL` (14-day window, `title IS NOT
   NULL`, ordered by `tokens_input + tokens_output DESC`), call
   `OpenBoxSessionList.map` in `load(from:)`, add `sessionList` to the
   snapshot. No `LIMIT` in SQL (no param binding; mapper caps).
4. Remote path untouched: `RemoteOpenCodeLoader` builds snapshots without
   `sessionList` → tolerant decode yields `[]` → section hides. Assert this
   in the Phase 1 mapper tests is not needed; the decode test in step 2
   covers missing-key behavior at the JSON layer.

**Verification:** DeckSharedTests green (SQL + decode suites).
**Dependencies:** Phase 1 (reader calls the mapper).
