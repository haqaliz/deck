# ClipBox — Implementation Plan

Date: 2026-08-13 · Input: `docs/planning/clipbox/prd.md`

## Phase 1 — ClipBoxCore scratch package (TDD)

**Goal**: pure logic — pasteboard classification, preview formatting, history
merge/dedupe/trim/text-cap — proven by tests before any app wiring.

**Files touched**: `ClipBoxCore/` (scratch SwiftPM package at worktree root,
removed in Phase 6; DevBox/OpenBoxTools precedent).

**Steps**:
1. `ClipBoxCore/Package.swift` + `Sources/ClipBoxCore/ClipModels.swift`:
   `ClipKind` enum (`text/image/file/other`), `ClipItem` (id, date, kind,
   previewText, detailText, content?), `ClipboardSnapshot`-shaped history
   container.
2. `Sources/ClipBoxCore/ClipClassifier.swift`: classify a pasteboard type
   list → kind (`public.string`/`public.rtf`/`public.html` → text;
   TIFF/PNG/JPEG → image; `public.file-url` → file; else other).
3. `Sources/ClipBoxCore/ClipPreview.swift`: preview + detail formatting —
   text → first line truncated (1/2-line variants), image → "Image" +
   best-effort "· 1.2 MB", file → last path component, other → "Other".
4. `Sources/ClipBoxCore/ClipHistory.swift`: merge(current items, new item) —
   dedupe on normalized top content (update timestamp, don't duplicate),
   trim to maxCount, 4 KB per-item text cap.
5. Tests (`Tests/ClipBoxCoreTests/`): classifier per type list; preview per
   kind + truncation; merge dedupe/trim/cap (RED → GREEN → REFACTOR).

**Verification**: `swift test` in `ClipBoxCore/` — all green.

**Dependencies**: none.

## Phase 2 — Shared data layer

**Goal**: snapshot model + store + host sampler + settings struct, compilable
in all three targets.

**Files touched**: `native/Shared/ClipBoxSnapshot.swift` (new),
`native/Shared/DeckSettings.swift`.

**Steps**:
1. `ClipBoxSnapshot` (Codable: `writtenAt`, `items: [ClipItem]`) +
   `ClipBoxSnapshotStore` (file `clipbox.json` in `DeckSettings.containerDirectory`,
   load/save copied from `GitBoxSnapshotStore`).
2. `HostClipBoardSampler.snapshot(maxCount:) -> ClipBoxSnapshot?` — reads
   `NSPasteboard.general` (type list → `ClipClassifier`, top content →
   `ClipHistory.merge` with prior `ClipBoxSnapshotStore.load()`), re-writes
   **every tick** (writtenAt freshness, PRD 6.7); returns `nil` only when the
   pasteboard is unreadable.
3. `ClipBoxSettings` in `DeckSettings.swift` with tolerant decode (PR #8
   pattern): `showList = true`, `historyCount = 5`, `textColor = RGBA(.indigo)`,
   `imageColor = RGBA(.pink)`, `fileColor = RGBA(.blue)`, `otherColor = RGBA(.gray)`.
4. `DeckSettings`: add `var clipbox = ClipBoxSettings()`.

**Verification**: `xcodegen generate` + `xcodebuild` Release build green.

**Dependencies**: Phase 1 (ported logic).

## Phase 3 — Agent + app data wiring (with empirical probe)

**Goal**: snapshot flows end-to-end; the background-pasteboard risk is probed
for real.

**Files touched**: `native/DeckAgent/main.swift`, `native/DeckApp/DeckApp.swift`.

**Steps**:
1. `DeckAgent/main.swift`: after devbox — `if let clip = HostClipBoardSampler.snapshot(maxCount: settings.clipbox.historyCount), clip != ClipBoxSnapshotStore.load() { save }`.
2. **Probe**: run the built `DeckAgent` binary directly from the terminal,
   then inspect `clipbox.json` — must contain the clipboard's current text
   (copy a known string first). If the pasteboard read is empty from the CLI,
   STOP and re-open the PRD (fallback: read via `pbpaste` subprocess).
3. `DeckApp.swift`: `refreshClipBox()` (host-side, mirrors `refreshGitBox`),
   wired into `onAppear` + 60s timer; sidebar `DeckWidget.clipbox` case
   (title "ClipBox", systemImage "doc.on.clipboard") — tab view placeholder.

**Verification**: probe passes; `xcodebuild` Release green.

**Dependencies**: Phase 2.
