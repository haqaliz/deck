Deck

Fourteen small, beautiful macOS desktop widgets in one native app — plus a quick‑search panel.

Download — latest release
brew install --cask haqaliz/deck/deck

Free and open source · macOS 15+ · Apple silicon & Intel

Fourteen widgets, one app

Real WidgetKit widgets on your desktop — no floating window cards. Each comes in small, medium and large.

LiveBox

CPU, memory and disk with a live chart, top processes and threshold coloring.

OpenBox

opencode usage: tokens, cost, a 14‑day chart, models and sessions.

NetBox

Per‑interface up/down rates and history.

BatBox

Battery level and time remaining, plus Bluetooth accessory batteries.

GitBox

Commits per day, today’s count, streak and active repos.

DevBox

Open TCP ports and running Docker containers.

ClipBox

Clipboard history, local only — passwords are skipped.

WeatherBox

Conditions and a 3‑day forecast for your location.

ClockBox

World clocks for up to six cities.

ShipBox

GitHub Actions runs across your repos, merged newest‑first.

TaskBox

Azure DevOps work items: open count, current sprint, board lanes.

CalBox

Today and tomorrow’s events from every calendar macOS syncs.

PRBox

Your open PRs and the ones awaiting your review — GitHub and Azure DevOps in one queue.

MarketBox

Crypto, fiat, gold and US stocks in one display currency.

Search

Press ⌥Space for a floating panel that searches the services your widgets already use. It stays out of the way — silent until you open it, and it shows nothing on your desktop you didn’t ask for.

  • pr pull requests
  • mkt markets
  • cal calendar
  • commit commits
  • run CI builds

Install

Download

Open the disk image and drag Deck to Applications.

Latest release

Homebrew

brew install --cask haqaliz/deck/deck

Then right-click the desktop → Edit Widgets… → search “Deck”.

Run this line before opening Deck the first time.

xattr -dr com.apple.quarantine /Applications/Deck.app

Deck isn’t notarized yet, so macOS quarantines it on download. Launching it while it is still quarantined does not just warn — macOS deletes the app, and not to the Trash. If that already happened, install again and run the line above first.
